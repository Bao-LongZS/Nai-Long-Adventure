## 动效分组

| Group | 帧 0 → 1 → 2 → 3 | 视觉意图 |
|---|---|---|
| 射击/命中 | 弹体飞出 → 接近命中 → 命中星爆 → 残余环淡出 | 短促点状反馈，不遮挡敌人主体 |
| 清障/开位 | 障碍受击 → 大裂纹出现 → 箱体崩裂 → 空建造位亮起 | 依次表达损伤、碎裂、位置开放 |
| 升级/金币 | 升级箭头 → 金色脉冲 → 金币弹出 → 新级确认 | 金币表现短促，最终帧显示升级完成 |
| 受扰/恢复 | 干扰闪电进入 → 紫色脉冲与禁用叉 → 受扰保持 → 绿环与勾恢复 | 红叉清楚表示暂不能攻击，恢复帧单独可识别 |
