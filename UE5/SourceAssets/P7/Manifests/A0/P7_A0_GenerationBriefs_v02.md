# P7 A0 提示词记录 v0.2

本修订使用 OpenAI 内置 ImageGen。此前因用户指出生成角色偏蛙形，后续四张用户提供图片被明确指定为标准奶蛙参考。外部图片只作为视觉参考，没有复制进仓库。前一轮提示词仍见 `P7_A0_GenerationBriefs_v01.md`。

## Frame 0 - standard milk-frog glance/smile

四张参考分工：桌面概念图负责光滑侧面轮廓；`Big_Laugh.png` 负责大笑表情；`Glance.png` 负责眼神和嘴线；`player.png` 负责直立身体比例。目标为 HUD 用 2D 头像：一个连续蛋/梨形金黄色头身、奶油色肚皮、较小嵌入式绿色眼睛、简短微笑嘴线、短手臂贴腹、短腿深色脚；轻微侧向观察，头身比例适中。排除外凸蛙眼、蹲姿、蹼足、疣点、宽扁蛙脸、长吻、服装道具、文字和背景。

## Frame 1 - same character laughing

从 Frame 0 编辑，只改变面部表情和手臂/手势；锁定头身轮廓、比例、颜色、角度、画幅与脚的位置。眼睛改为开心弧线，嘴张开但控制为整洁的小笑口，双手轻扶肚皮；不改变身体结构，不添加蛙类形态、背景或道具。
