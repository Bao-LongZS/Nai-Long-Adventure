## 方向与边界

用户提供的《捧腹大笑思想与奶龙学概论》用于奶蛙身份和情绪基调参考：明亮、轻松、无厘头但友好，带一点自嘲式喜感。奶蛙候选保留圆润金黄色身体、浅色肚皮、绿色眼睛和深色手部，以自然微笑表达快乐。按 P7 玩法基线，奶蛙只作为 HUD 头像候选，不进入战斗场景。

该资料不作为 P7 工程规则或美术生产规格；图书页面、版式和图片没有复制到仓库，也没有作为交付背景。P7 塔、防守敌人、障碍、地面和 UI 状态均为本项目原创设计。

用户确认将两张表情作为一组：v02 睁眼微笑为前帧，v01 闭眼大笑为后帧。两张用户附图与这两个项目 PNG 的 SHA-256 分别完全相同，因此直接使用现有源图，没有复制重复文件；横向两帧 sprite sheet 与帧顺序 JSON 已生成。大笑张嘴是用户选择的表演，不视为需删除的变体。
