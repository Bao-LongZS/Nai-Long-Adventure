## 交付内容

- `SourceSheets/`：11 张原始透明三视图条带，均为 2172×724 RGBA。图像原件保留，未做像素修绘。
- `Frames/<action>/`：从每张条带按等宽列无损拆出的独立 724×724 帧，共 33 张。
- `../../../Manifests/P4_A1_Animation_manifest.json`：动作、朝向、源矩形、帧文件、哈希、alpha 可见矩形和脚底锚点估算。
- `../../../../../Records/p4_alpha/evidence/W2/P4_A1_Animation_review.html`：逐姿势正/背/右侧面预览页。
- `UE5/Scripts/p4_package_a1_animation.py`：可重复执行的三列拆帧、manifest 和预览页生成脚本。

动作数量：待机 3、移动 6、普攻 6、冲撞 6、防御 3、受击 3、大笑 6，合计 33 帧。源图含正面、背面、右侧面；运行时左侧面水平镜像右侧源图。

负责人指出原“大笑张开”姿势（双臂向两侧完全张开）不要。该版本已从项目资源包剔除，改为双臂收拢、抱肚发笑的姿势。当前源图和逐帧导出仅包含替换稿，且该替换稿包含在本次通过范围内。

## 生成规格

使用内置 `image_gen`，以 A0 通过样片和待机姿势作角色参考。共用提示为：透明背景、同一只黄身绿眼奶蛙、浅色腹部与棕色手足、保持短圆梨形体态、正面/背面/右侧面三格全身图；各姿势再分别指定移动跨步、普攻起手/接触、冲撞起步/跨步、防御、受击、大笑收拢抱肚/回收。避免肌肉化、凶狠表情、道具、文字和特效。按负责人要求排除双臂完全伸展的大笑版本。
