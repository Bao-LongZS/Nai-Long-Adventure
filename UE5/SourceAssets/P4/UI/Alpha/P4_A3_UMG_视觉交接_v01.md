## 2. 卡面视觉参数（浏览器参考值）

- 桌面预览容器最大宽度 1440 px，三列等宽，列间距 20 px；卡片最小高度 516 px。
- 卡面顶部分类线：子弹 `#D59A3B`、冲撞 `#78A86C`、大笑 `#D98273`。纸面 `#FFF8E9`，主描边/文字 `#49372E`。
- 卡面插图区高 154 px，图标显示 128×128 px；实际 UMG 图标需按目标 DPI 和 720p/1080p 截图验证，不能直接把 CSS px 当成 Slate 尺寸。
- 标题参考 23 px；效果正文 14 px；分类 13 px；组合/触发说明 12 px。字体为预览系统字体回退；工程使用项目允许的中文字体并检查字重、行高与换行。
- 已选卡通过抬升、暖金边框、背景和勾选符号共同提示；焦点态必须保留清晰外描边。已获得状态置灰并显示“本局不重复出现”。
- 类别冗余线索：子弹圆点 + “子弹强化”，冲撞菱形 + “冲撞强化”，大笑星芒 + “大笑强化”。灰度预览通过仅代表形状/文字仍可区分，不代表色觉模拟或正式无障碍验收。

## 3. 交互与数据合同

1. 一次只能有一张可选卡处于 selected 状态；选择更新选中边框、勾选和辅助文字。
2. v03 视觉样片覆盖鼠标选择及 Tab/Enter/Space；UE 输入组件应把焦点导航交由项目输入配置，并确认手柄/无障碍导航策略后再定稿。
3. “已获得”样例仅表示不可选态；真实卡池仍由数据源判重，不由 UI 隐藏卡片代替。
4. 确认按钮在视觉样片中不产生游戏或存档写入。正式接入须由工程绑定确认事件、奖励发放和防重复提交；UI 只反映返回结果。
5. 3 张样例代表卡仅用于审阅布局，不是固定 offer。卡池顺序、章节标题和强化进度需使用运行时数据绑定。
