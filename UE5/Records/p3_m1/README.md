# P3 M1 手感测试沙盒

M1 使用隔离地图 `L_NaiwaP3_M1Prototype` 和专用 `NaiwaP3M1GameMode`。这是一个 15×11 的无胜负测试场：中央区域用于移动与转向，四组木箱用于观察炸弹范围和软砖阻挡，中央长廊可观察连锁，外环用于观察奶察巡逻，出生点旁标出了贴弹后的逃离路线。

## 操作

- `WASD` 或方向键：移动；松开按键停止。
- `Space` 或 `J`：放置标准炸弹。
- `1`–`4`：切换标准十字、豆奶大十字、奶茶圆爆、奶鼠分裂弹。
- `T`：重置场地并在中央链道布置四枚测试炸弹，观察 0.2 秒连锁节奏。
- `R`：恢复初始地图、角色和巡逻状态。

测试场没有胜利或失败结算。火焰期间不能进入危险格，爆炸命中数会显示在右侧读数中。

## 调参

参数集中在 `Naiwa P3 M1 Test` Developer Settings 和 `Config/DefaultGame.ini` 的 `[/Script/NaiwaRuntime.NaiwaP3M1Settings]`：

| 参数 | 默认值 |
|---|---:|
| 玩家速度 | 4 格/秒 |
| 奶察巡逻速度 | 2 格/秒 |
| 炸弹容量 | 1 |
| 放弹冷却 | 0.4 秒（同时在场容量仍单独限制可放置数量） |
| 十字臂长 | 1 格（中心格加四向各一格，最多 5 格） |
| 引爆时间 | 2.5 秒 |
| 连锁延迟 | 0.2 秒 |
| 火焰持续 | 0.3 秒 |

运行时逻辑按 0.1 秒固定 tick 推进；时间参数会量化到 tick。更改配置后重新启动沙盒，HUD 会显示实际生效值。
