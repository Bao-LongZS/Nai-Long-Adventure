## 二、导入步骤

1. Content Browser 里建目录 `Content/Naiwa/P3/Audio/`
2. 把这批 wav 拖进去（`25_奶察发现.mp3` 跳过），**导入时逐条改名为上表的资产名**
3. 导入后逐条设：
   - `BGM_P3_Level`：**Streaming（勾流式）**，Looping 不勾（循环靠 Sound Cue 设区间）
   - `AMB_P3_Conveyor`、`AMB_P3_Rain`、`AMB_P3_LowDrone`：**勾 Looping**
   - 其余 22 条：默认（不勾 Looping），压缩保持默认

## 三、要新建的资产（只有 8 个）

| 类型 | 名字 | 参数 |
|---|---|---|
| Attenuation | `ATT_P3_World` | InnerRadius 300 / Falloff 1500 / 距离衰减 Linear |
| Attenuation | `ATT_P3_Area` | InnerRadius 800 / Falloff 2000（传送带、雨声用） |
| Attenuation | `ATT_P3_2D` | 无衰减（玩家自身、UI） |
| Concurrency | `CC_P3_Explosion` | Max 6 / 声音可杀旧 / Volume Scale 0.55 |
| Concurrency | `CC_P3_SmallPop` | Max 8 / 排队不杀 / Volume Scale 0.5 |
| SoundClass | `SC_P3_BGM` | 父级 Master，默认音量 0.7 |
| SoundClass | `SC_P3_SFX` | 父级 Master，默认音量 1.0 |
| SoundClass | `SC_P3_Ambience` | 父级 Master，默认音量 0.5 |

## 四、Sound Cue 只建 3 个（其余直接播 SoundWave）

| Cue | 内容 | 关键设置 |
|---|---|---|
| `SCUE_P3_BGM` | `BGM_P3_Level` 单节点 | Looping 勾上，**LoopStart 1.50s / LoopEnd 195.50s**；挂 `SC_P3_BGM` |
| `SCUE_P3_Explosion` | `SFX_P3_Explode_Normal` | 挂 `ATT_P3_World` + `CC_P3_Explosion` + `SC_P3_SFX` |
| `SCUE_P3_SmallPop` | `SFX_P3_Explode_SmallPop` | 挂 `ATT_P3_World` + `CC_P3_SmallPop` + `SC_P3_SFX` |

其余 23 条音效**不需要 Cue**，代码里直接 `PlaySoundAtLocation` / `UGameplayStatics::PlaySound2D` 播 SoundWave 即可，Attenuation 和音量在调用时传。

## 五、必须记住的三个数值

1. **`18_死亡` 播放音量 −8 dB**——它峰值已削顶（1194 个采样打满），不压会爆音
2. **`05_奶茶径向爆` 播放音量 +8 dB**——原文件偏轻 7.7 dB，不补会听不出威力
3. **`24_迷雾揭开` 播放音量 −13 dB**——原文件偏响，不压会盖掉爆炸

（全表在 `_接入说明.md` §1，直接照填。）
