## §2 BGM 处理方案

| 项 | 参数 |
|---|---|
| 循环点 | **已实测（ffmpeg 抽样，不是估算）**：这首自带首尾淡化。首 2 s 平均 −26.1 dB（中段 100 s 处 −19.4 dB），尾段 194 s 还有 −20.2 dB、**196 s 掉到 −48.6 dB、198 s 后基本静音**，末尾约 5.5 s 空尾。**不要用 0–201.46 s 整曲循环**，否则每圈"掉一口气"。建议 **LoopStart 1.50 s / LoopEnd 195.50 s**（跳过 1.5 s 淡入与 5.5 s 空尾），循环段 194 s；若接缝仍可闻，加 0.5 s 交叉淡化 |
| 进关淡入 / 通关淡出 | 进关 1.5s 线性 0 → -8dB；通关 2.0s：`21_通关` 起播后 0.3s 开始把 BGM 拉到 -80dB |
| 狂暴·低通 | BGM 走独立 Submix，狂暴时挂 Low Pass：Cutoff 20000 → **800Hz**，Resonance 0.7，过渡 0.4s；结束后 0.8s 恢复 |
| 狂暴·降调 | Pitch **0 / -200 cents**，过渡 0.3s（约 0.891 倍速，曲子整体变慢变闷，阴间感主要靠这一项） |
| 狂暴·叠加 | 同帧起 `23_狂暴stinger`（-3dB）+ `26_低鸣氛围`（-17dB，每 2s 一次） |
| BGM 电平 / 文件处理 | -8dB（使 BGM RMS ≈ -20dBFS，比爆炸 200ms 峰低约 9dB）；320k CBR 单曲 8.93MB 过大，改 96k（≈2.4MB）或 Bink q50，对钢琴绰绰有余 |
| Ducking | 在 SFX 组的 Ducking 里加 Target = BGM：**-4dB**，Attack 0.05s，Release 0.7s；Ambience 压 -2dB。不压超过 -5dB，否则欢快钢琴的喜剧反差会被压没 |

## §3 三条最容易出事的规则

**① 同帧多爆（一屏 20 颗同时炸）**
- 并发资产 `CC_P3_Bomb`：Max 6，Volume Scale Mode = Polynomial，Volume Scale 0.55，Coefficient 1.0；**第 7 路起直接丢弃，不排队**（排队会变成"连环屁"）。
- 时间结构：引信 2.5s（25 tick），连锁每颗 **0.2s** 递延——链条本身已经把爆炸摊开，真正"同帧"只发生在尖刺顶爆同格多枚、或多枚连锁在同一帧汇聚时。只对这一类同帧组做错帧：第 i 颗延迟 i×12ms，上限 60ms；pitch ±4% 让相位不撞。
- `05` 必须先 +8dB 修好，否则 20 颗一起炸时玩家只听到一串奶蛋的"噗"，奶茶弹毫无存在感。
- 同帧 >8 颗时，额外触发一次 `04` 的**前 1.2s 截断版**（-6dB）作"整片塌了"的兜底，把密集的滴滴声合成一次性冲击；主总线挂 Limiter（阈值 -1dBFS、Release 50ms），6 路 0dB 叠加最坏 +7.8dB 靠它兜，不许硬削。

**② 循环音的接缝（09 / 16 / 26）**
- 实测三条都**自带首尾淡化**，所以直接勾 Looping 听到的不是"咔"一声，而是每圈一次**掉音量的呼吸**：
  `09` 首 200ms 从 -50 爬到 -26dB、尾 120ms 掉到 -57dB（主体稳定 -15dB）；`16` 首 **3s** 淡入（-79 → -37dB）、尾 **1.2s 静音**（334.0s 之后）；`26` 首 120ms / 尾 220ms 淡化，且只有 0.8s。
- 落地：`09`、`16` 用 MetaSound Source 双 Wave Player（A/B）交叉淡化 0.8s，LoopStart/End 见 §1；`16` 那 1.2s 尾部静音会让"雨停了"的错觉每圈出现一次，LoopEnd 必须收在 334.00s；`26` **绝不循环**（0.8s 循环 = 每秒一次喘息），只能当一次性低频触发。
- 48kHz：循环母带建议重导 48k。暂不重导也能用，UE 自动重采样、接缝误差 ≤1 帧（0.02ms），不致命——真正的问题是上面那条淡化，不是重采样。

**③ 低频提醒（03 / 26）**
- 实测：`03` 的 200Hz 以上能量 **-26.6dBFS**，`02` 是 **-20.3dBFS** → 03 的中高频比奶蛋爆炸低 6.3dB；`26` 有 **92% 能量在 200Hz 以下**，中高频只剩 -18.8dBFS。
- 笔记本外放 250Hz 以下基本无输出 → 这两条在笔记本上近乎"没触发"。而豆奶弹（威力 ×1.9）是玩法上最重要的正反馈，笔记本玩家会以为炸弹坏了。
- `03` 允许用：只在有低音炮的场合与 `04` 同帧叠加（-6dB）。**豆奶爆炸只能用 `04` 当主音。**
- `26` 允许用：只当低频支撑层（与 16 或 09 叠加），不能单独承担"阴森氛围"，氛围的可听内容必须落在 200Hz 以上（BGM 低通后的残余 + 16 雨声）。通则：任何依赖低频的场合都同时挂一层 200Hz 以上提示层，别指望低频传达到位。
