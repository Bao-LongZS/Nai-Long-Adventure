## 2. 复用候选判定

| 候选 | 计划处理 | 放行条件 |
|---|---|---|
| Common 通用 UI 底板、字号/间距 token | 仅候选 | P7 实际引用；两种分辨率和色盲/灰度检查通过；保留唯一原稿路径 |
| P3/P4/P5/P6 角色图或场景件 | 不默认复用 | 视角、造型身份、明度、边缘、许可/来源、尺寸均经样片验证；不复制源文件 |
| P3 音效 | 不默认复用 | 试听通过、来源与项目使用权确认、包内引用验证；否则不进入 P7 |
| P5 雪景或厚涂资产 | 不复用到扁平 P7 主题 | 风格不匹配；除非未来经用户明确改定视觉方向并重新评估 |
| 《保卫萝卜》画面、地图、名称、图标、音效 | 不导入、不临摹为交付件 | 只用公开产品描述研究高层机制；P7 资产需原创设计 |

## 3. 资产 ID / manifest 最低字段

`AssetId, Owner, SourcePath, Version, SourceHash, IntendedUse, Width, Height, FrameCount, AlphaMode, ColorSpace, ExportPreset, UnrealPath, ReuseStatus, ReviewStatus, EvidencePath`。

Common 的进入条件是：资源有稳定唯一源文件、至少两个关卡的实际调用路径、两处运行画面验收和负责人批准。未达到时留在 P7 并标记“候选复用”，不得把“看起来能用”记作已复用。
