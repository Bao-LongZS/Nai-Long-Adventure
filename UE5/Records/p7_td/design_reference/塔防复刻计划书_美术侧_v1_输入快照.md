## §1 结论先行：质感定在"扁平描边卡通"，这是全项目最省的一档

| 判断 | 内容 |
|---|---|
| **定档** | **L1 档：纯 2D 精灵 + 高饱和扁平 + 粗描边**（不做厚涂、不做视差、不做光照） |
| 保卫萝卜是不是纯 2D | **是。** cocos2d-x 纯精灵，没有任何 3D。它看着"立体"，靠的是**斜俯视画法**（地面压扁约 0.5）+ 前后遮挡排序，不是真透视 |
| 为什么跟着走纯 2D | ① 项目 P1/P2/P3 全是 Unlit 全 Emission（无光照），扁平是这套管线的舒适区 ② P1（正交侧视）、P3（正交顶视）已有两套正交先例，零新相机代码 ③ 精灵零畸变，塔与敌人的描边能保持同一粗细 |
| 与 P5 的差别 | P5 滑雪要"雪面体积"，做了 3 层视差 + 双色明暗；TD 是看棋盘，**只要一层画死的地面**。**P5 的雪地素材不能搬过来**（厚涂 vs 扁平会立刻穿帮） |
| 人天对比 | 扁平 41 天 ／ 若照 P5 走厚涂 ≥ 80 天，且 18 塔 × 3 级根本画不完 |

**一句要提前认的账**：TD 会比 P5 滑雪"平"。这不是退步，是塔防这类玩法**必须让 60 个物体同时可读**，厚涂会互相打架。

### §2.3 三条硬规则

1. **描边**：1024 画布 → **14 px**（= 512 画布 7 px）。颜色 = 物体主色压暗 **35%**，**不用纯黑**（纯黑会让整屏发脏）。
2. **光照**：只有**左上 45° 一个光源**，只画**两层**（底色 + 一层暗部）。**禁止渐变、软阴影、景深、写实材质**——这三样是"看起来像另一个游戏"的主要来源。
3. **明度阶梯**：背景 70–85% 明度，可破坏物 55–70%，塔 45–65%，敌人 30–45%，弹道/VFX 最高。**去色后必须仍然一眼分层**。

### §2.4 图形语言（识别成本靠这个，不靠细节）

| 形状 | 含义 | 用在哪 |
|---|---|---|
| 圆 + 大口 | 会喷东西的装置 | 奶泡炮、奶章、奶桶 |
| 方 + 铆钉 | 机械/固定 | 奶弩、奶锚、奶火箭 |
| 尖 / 齿 | 危险 | 奶针、奶叉、尖刺障碍 |
| 软 / 有四肢 | 生物 | 全部敌人 |
| 直立 + 底座 | **不会动**＝塔 | 所有塔都必须有底座 |
| 横向 + 无底座 + 低饱和 | **会动**＝敌人 | 所有敌人 |

> 这条是塔防最重要的一条：**玩家要在 0.3 秒内分清"这是我的"和"那是敌人"**。塔一律高饱和 + 底座；敌人一律低饱和 + 无底座 + 面向行进方向。

## §4 生图规格（可直接照做）

### §4.1 画布与构图

| 项 | 规格 |
|---|---|
| 画布 | **1024×1024**（最终 512 输出，2× 冗余） |
| 主体占比 | 高 **70%**，水平居中 |
| 接地线 | 脚底距画布底边 **8%**（否则程序里贴地会浮空） |
| 背景 | **纯透明**（不是白底；白底抠图会吃掉描边） |
| 视角 | **斜俯视 55° 画法**——从上往下看、地面压扁 0.55，但**正脸仍可见**。注意：这是**画法**，不是相机倾斜；相机是正交的 |

### §4.2 Prompt 模板（中英混合，负面词必带）

```
正面：{主体描述}，扁平卡通风格，粗描边（描边色为主色压暗），
高饱和，左上 45° 单光源，两层明暗（底色+一层暗部），
斜俯视 55 度（地面压扁 0.55），脚底接地，全身完整，纯透明背景，
无渐变，无写实材质，无景深，游戏素材，矢量感

负面：写实，3D 渲染，渐变，软阴影，景深，模糊，照片，
复杂细节，多重光源，投影在地面，文字，水印，白底
```

**逐组补充词**（避免一次生 200 张全一个味）：
- 塔：`机械装置，底座，铆钉，金属+糖果色`；控制塔加 `紫色，符文，冰晶`
- 敌：`矮胖，低饱和，四肢，表情滑稽，面向右侧（行进方向）`
- 可破坏物：`木箱/雪堆/岩石，裂纹，可直接打碎`

### §4.3 命名与交付

`T_TD_<组>_<id>_<态>.png`，例：`T_TD_Tower_tower_bottle_L1.png`、`T_TD_Enemy_enemy_bunny_walk02.png`
导出后**先按组放同一目录**，由工程侧统一导入并在 `Content/Naiwa/TD/Art/` 建 atlas（美术不手工拼图）。

## §6 与 P1–P5 的一致性（这是最容易翻车的一节）

| 冲突源 | 表现 | 处理 |
|---|---|---|
| P3 夜巡冷调 vs TD 白天高饱和 | 摆在一起像两个游戏 | **不统一**，用叙事包装：P3 是夜、TD 是白天；但**描边规则全局统一**（P3 补描边只需 1 人天） |
| P5 厚涂 vs TD 扁平 | 同一台机器上两种质感 | **素材不互通**：P5 的雪地是厚涂 + 视差，TD 是画死的扁平，搬过来就是贴片（Kenney 那次翻过）。TD 一格都不借，只对齐描边宽度与色板 |
| P1/P2 平涂 | 反而最接近 | TD 的扁平就是 P1/P2 的延伸，只需统一描边宽度 |
| 奶蛙 3D 模型在场边 | 3D 与 2D 立绘同框 | 场边奶蛙用**纯色 Unlit 材质 + 描边后处理**，与 2D 同色板；不要带光照 |

**统一动作只有一条**：描边宽度 = 屏幕高度 0.55%（1080p ≈ 6 px）。全项目照这一个数走。

## §8 验收口径（三条硬测，不过就重做）

| # | 测什么 | 通过标准 |
|---|---|---|
| 1 | **1 秒识别** | 找没玩过的人看截图 1 秒，能说出"哪些是我的塔、哪些是敌人"，正确率 ≥90% |
| 2 | **灰度分层** | 整屏去色后，背景/障碍/塔/敌人仍然四层分明，不糊成一片 |
| 3 | **色盲可辨** | 红绿色盲模拟下，五种功能色仍能靠**形状**区分（颜色只是加速识别，不能是唯一线索） |
| 4 | 一致性 | 18 塔并排摆开，描边宽度、光源方向、暗部层数三项目视一致 |

## §9 风险

| # | 风险 | 触发 | 缓解 |
|---|---|---|---|
| A1 | 生图风格漂移 | 200 张分几十次生成 | 先定 3 张"母版"（1 塔 / 1 敌 / 1 障碍），后续全部以母版做参考图 + 同一段 prompt 前缀 |
| A2 | 描边粗细不一 | AI 不保证 | 生成后用统一描边脚本（阈值 + 膨胀）二次处理，不靠 AI |
| A3 | 18 塔长得像 | 都是"奶制品装置" | 强制"每塔一个主形状 + 一个功能色"，先出黑白剪影表确认可区分再上色 |
| A4 | 路径与底图的地面接不上 | 底图与 tile 的格线对不齐 | 底图画的时候就把 **96×53** 的格线打进去（或只画纯色地面），tile 只负责路径本身，不承担地面纹理 |
| A5 | 雪主题借用 P5 素材 | 图省事 | **明令禁止**：P5 是厚涂，混进扁平会立刻穿帮 |
