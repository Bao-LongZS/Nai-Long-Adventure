## Run、状态与混合

Run 周期 `0.666666687 s`，在原生代理中仍使用状态名 `Walk`。代理选择 `RunSequence`，未赋值才回退原 `WalkSequence`。播放率为 `clamp(|Vx|/max(1,300),0.1,2.0)`，300 cm/s 时为 1.0。

- 空中 `IsFalling` → Jump；落地后 `|Vx|>3` → Walk/Run，其余 → Idle。
- 状态过渡 **0.12 s**。各状态权重以恒速逼近 0/1，再归一化，先混 Idle/Run，再混地面/Jump。
- 进入新状态清零其时钟；Idle/Run 循环，Jump 保持到动作长度的 **0.55**，约 0.435416678 s；落地立即选择地面状态。

- Reset 解除暂停、停止跳跃、清速度和移动输入、恢复出生位置与向右朝向，并递增重置代数清动画时钟。
