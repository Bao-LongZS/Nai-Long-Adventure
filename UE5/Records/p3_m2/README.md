# P3 M2 推进记录

更新日期：2026-10-28。按主理人确认的顺序，先完成 M2 系统，再制作独立场景化测试关供审阅，之后才进入正式 3-1 和 3-2。M1 手感原型与本测试关是两个不同交付物。

## 已完成的数据与运行逻辑

- `FNaiwaP3M2SeededMapGenerator` 生成 3-2（23×17）候选地图；主种子为 `levelId × 10000 + attemptCount`，并派生地图、掉落、脚本 AI 三条独立随机流。固定放置出生/出口、五枚金蛋、五种机关和五名敌人；通过 BFS 连通校验、最多 64 次候选和确定性软砖修路，并输出布局哈希。
- 接入四种炸弹形态：标准十字、豆奶大十字、奶茶圆爆、奶鼠分裂弹。按键 1–4 选择，按类型着色；放弹间隔为 0.4 秒（4 个固定 tick）。主弹按布局种子、格子和放置序号确定 2% 哑火概率，哑火后延至 5 秒引爆；子弹不参与哑火抽取。奶鼠分裂最多生成三枚子弹，视觉从母弹位置滑到相邻空格，并在 0.2 秒后引爆。
- 掉落权重表和独立随机流按 `LootStreamSeed` 初始化；原权重合计 105，运行时按权重归一化。
- 新增玩家道具状态模型：容量上限 3、威力上限 4、奶鸡跳 8 秒冷却、护盾次数、永久速度提升上限、透视/反向操作 3 秒。
- 新增五种机关的固定 0.1 秒 tick 状态模型：传送门冷却、踩板门延迟、尖刺周期与顶爆炸弹、传送带方向查询、断裂地板烧毁/塌陷/洞持续时间。参数可在 `DefaultGame.ini` 调整。
- 新增战争迷雾可见数据模型：普通半径 7 格、狂暴时 10 格，硬砖和软砖遮挡视线，走过区域保留地形记忆。
- 新增 `FNaiwaP3M2LevelSession`，把种子地图、机关、掉落、玩家道具、金蛋拾取与迷雾合到同一会话/tick；可处理砖块破坏、掉落生成/拾取、金蛋计数以及火焰通知。
- 新增确定性敌人决策器：奶察的巡逻态/视线追击/搜索/返岗与危险回避，奶杀的快速追击/软砖受阻投弹请求，奶豪的近距剧本投弹，奶雨的远程冷却攻击；脚本 AI 使用地图派生的独立随机流。奶察/奶杀看不到玩家时会改追逐可用掉落，拾取后提升炸弹容量、威力、移速或获得爆炸护盾，并让增益实际作用于战斗。奶雨攻击锁定玩家所在格，提前 0.8 秒显示五格十字预警，命中后减速 3 秒，离开十字范围可躲避。
- 新增爆炸危险预报：按地图砖墙阻挡计算标准弹、大十字、圆爆、分裂弹及子弹的爆炸格，处理软砖先行破坏与连锁引爆顺序，输出起火/熄灭 tick 供 AI 避险。
- 扩展 `UNaiwaP3M2RuntimeSubsystem`：标准/豆奶/奶茶/奶鼠炸弹现在在 M2 地图格上实际生成、倒计时、爆炸、破砖、连锁、点燃与伤害；加入炸弹所有者标记，敌方炸弹不占玩家容量。传送带推弹、地洞吞弹、尖刺顶爆接入同一固定 tick。集齐五枚金蛋后触发狂暴：奶察提速 30%，每 6 秒投一枚标准弹、忽略自身炸弹；迷雾半径由既有狂暴状态扩展。
- 将玩家 Pawn 输入接入 M2 运行时：移动、放弹、1–4 选弹、奶鸡跳均由活跃会话处理；敌人意图驱动敌人格移动与投弹，实体位置使用插值表现。
- 新增 `ANaiwaP3M2GameMode` 与中文 `ANaiwaP3M2HUD`：可通过 GameMode 启动随机布局候选、创建棋盘/敌人表现并注册玩家；HUD 显示金蛋、生命、敌人数、炸弹配置、探索格数和中文操作说明。系统状态新增集齐金蛋后抵达出口撤离与生命耗尽失败；R 键可按相同布局种子重开。
- 新增 `ANaiwaP3M2WorldPresentation`，在棋盘上展示金蛋/出口、传送门、踩板、金库门、尖刺、传送带、断裂地板和道具掉落，并同步开门、尖刺、塌陷、出口解锁状态。
- 迷雾现在有未探索格深色遮罩；记忆区地面、砖块主体、机关和出口压暗至约 56% 亮度并保留暗边，敌人、炸弹和掉落只在可见格显示。爆炸火焰持续期间脉冲闪动，HUD 在爆炸后全屏闪照 0.3 秒，火焰离开可见区即隐藏；狂暴扩大的视野也实时驱动遮罩。
- 新增独立地图 `L_NaiwaP3_M2ScenarioTest` 并绑定 M2 GameMode，默认候选为 attempt 0 / seed 320000、23×17。地图内保存了同种子的编辑器可见场景预览，包含地形、软砖/硬砖、金蛋、出口、五种机关与敌人；预览物体在游戏内隐藏，运行时由 M2 GameMode 生成真实棋盘与系统，避免重叠。HUD 标题统一为中文“场景化测试关”。
