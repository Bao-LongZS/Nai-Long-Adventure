## 预算口径

- P4 α：**20–30 工程人天 + 10.7–16.9 美术人天**，总计 **30.7–46.9 人天**（约 31–47）；原 20–30 不再被误读为含完整美术交付的总工期。
- 完整 P4 工程：α 20–30 + β 32–52 + γ 10–19 = **62–101 工程人天**。
- β/γ 美术尚未估算；α 出口门决定是否继续十章。不能把 62–101 报成全项目（含美术）的总人天。
- 所有估算按 1 人天=6 小时有效工作计；没有人员到岗表时只报人天，不虚构自然周或日历完成日。
