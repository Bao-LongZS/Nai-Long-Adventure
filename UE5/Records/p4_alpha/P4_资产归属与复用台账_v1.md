# P4 资产归属与复用台账 v1

适用：本项目 `Nai-Long-Adventure` 的 P4 奶蛙擂台子模式；对应计划：[P4 完整计划 v2](P4_完整计划书_v2.md)、[美术计划](P4_美术执行计划_v1.md)。

## 1. 归属规则

P4 属于同一个 UE 项目 `UE5/NaiwaP0`，不是独立仓库或关卡编号。P4 源资产放 `UE5/SourceAssets/P4/`，P4 运行时导入件放 `UE5/NaiwaP0/Content/Naiwa/P4/`。通用资源只允许经审核后由其原始 P2/P3 路径引用；不为“整理整齐”复制一份到 P4，也不把未验收旧资源搬进 Common。

状态：

- `P4 独占`：只用于 P4 子模式，源和 `.uasset` 均落 P4 路径。
- `候选复用`：有源资产但尚未通过 P4 镜头、比例、alpha、颜色、性能或数据引用测试；在表里标候选，不计作交付完成。
- `已验证引用`：经过指定验收并从原路径引用，记录验收截图/导入报告；保持单一源文件。
- `参考-only`：帮助确定造型/技术，不进入 Shipping 内容。
- `待生产`：正式资产尚无源稿或完成品。

## 3. 哪些可跨全项目复用

| 资产/组件 | 归类 | 准入规则 |
|---|---|---|
| 奶蛙/奶龙身份对照图 | 项目级参考，不是成品 | 只供角色造型审阅；不进 `/Game` |
| P3 玩家中性/受击静帧 | 跨关候选，当前非 Common 成品 | P3 M2 后仍需在 P4 机位测尺寸、脚底、转向、边缘；通过后以原 P3 path 引用；不会把两静帧误称为可复用动画 |
| P2/P3 通用场景网格/音效 | 跨关引用候选 | 必须有来源、授权/仓库路径、运行时软引用和视觉/听音验收；由 P4 变色/摆位生成的实例留 P4 |
| P4 角色 atlas、卡图、场景主题处理 | P4 独占 | 只能 P4 内部复用，除非另一个子模式书面复核同风格/姿态后增加消费者；不得预先放入 Common |
| P4 定步长/数据 CSV、模拟 hash | 工程代码/数据，不是美术资产 | 若其他项目阶段要复用，单独评审代码接口；本台账不迁移共用代码 |

当前没有足够证据将 P4 新美术资产登记为“全项目已复用成品”。共同玩家设定图片只属于参考。P4 的 2D 角色样式和 P5 手绘雪景图集风格不同，不能因角色名相同就共用动作帧。

## 4. SourceAssets 文件夹

```text
UE5/SourceAssets/P4/
├── Data/                       # CSV 数值源
├── Portraits/W1/               # W1 静姿技术样片（非生产）
├── Characters/Alpha/           # Alpha 33 帧角色 atlas 源
├── Environment/                # P4 色调/环境改配；引用资产不复制
├── UI/                         # P4 专属 HUD/卡牌图形
├── Manifests/                  # 帧/朝向/尺寸/UE 导入记录
└── References/                 # 方向图片/引用列表，标注非运行时
```

每个正式资产在 manifest 中登记 `AssetId / OwnerRole / SourcePath / ExportPath / Version / FrameRect / FootAnchor / AlphaMode / ColorSpace / UEImportSettings / RuntimeReference / Status / Evidence`。源稿、导出 PNG 和 UE `.uasset` 是三层不同产物；哈希/导入设置不得混成同一个“最终文件”。
