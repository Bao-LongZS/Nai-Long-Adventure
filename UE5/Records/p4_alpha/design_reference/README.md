# P4 历史设计输入与 authority

本目录复制了原工作区中的 `P4_竞技场设计_v1.md`（文档内设计版本 v2.0）与 `P4_章节数据_v1.json`（机器可读 v2.0），用于固定章节/卡/行为 ID 和现有设计范围。

解释冲突时按以下顺序：

1. `P4_完整计划书_v2.md`：本项目当前批准的边界、人员、工程/美术预算、阶段和验收裁定。
2. `P4_工程计划_v2.md` 与 `P4_美术执行计划_v1.md`：各自的任务、产物和验收合同。
3. 本目录的 P4 设计基线/章节 JSON：仍作为玩法文本、章节和卡池数据来源；但任何美术“零新资产”、3 天动画或未列责任人的旧估算均已由 v2 总计划和分轨计划覆盖。

特别说明：设计基线 §7 的“零新美术资产”只作为早期复用意图，不代表 P2/P3 内容已验收可用，也不代表角色动作/UI/预警无需制作。P4 资产归属和复用状态以 `../P4_资产归属与复用台账_v1.md` 为准。
