# P4 单屏清版竞技场 设计文档 v2.0

> **v2.0 变更**：① 全部角色名改入**奶家体系**（16 敌 + 4 Boss + 3 个章节名，映射表见 JSON `naming.rename_map`），P4 不再沿用任何参考游戏角色名；② 强化卡池**整池重写**为原创 15 张 + 1 张保底，配额 子弹 4 / 冲撞 3 / 大笑 3 / 防御 3 / 联动彩蛋 2，含 3 张纯基础子弹强化；③ 新增 **§0 子模式定位与主菜单入口**；④ 压缩 §7 / §13 腾行数（398 → 见文末行数）。**核心技能（奶球 / 冲撞 / 大笑 / 防御）数值与手感一个字未动。**

> 归属：**独立子模式 P4**（不并入 P1/P2/P3 任何关卡、不共享进度与存档槽）。独立地图 / GameMode / Pawn / 存档槽，只复用奶蛙 mesh、动画、音效。
> 基准：单屏 1280×720、3/4 斜视、8 向贴地、无主动跳跃。**玩法规则与数值基线属通用机制；全部名称、文本、卡池为本次原创。**

## §0 子模式定位与主菜单入口

### 0.1 定位一句话

**P4 是子模式，不是关卡**：它有自己的 10 章、自己的强化曲线、自己的存档槽；主菜单里它是一个**独立入口按钮**，不排进 `1-1 / 2-1 / 2-2 / 2-3` 的关卡卡序列。

### 0.2 入口位置（只加，不改）

| 项 | 取值 |
|---|---|
| 屏 | 选关页 `WBP_LevelSelect`（**结构不动**：启动页、4 张关卡卡、解锁链、`1-1→2-1→…` 路由、`UNaiwaSaveGame` 全部保持原样） |
| 区域 | 页面**底部新增一条独立「模式条」（Mode Strip）**：横跨屏宽、高 96 px，与上方关卡卡网格之间留 32 px + 1 px 分隔线；条内只放 1 个按钮块（水平居中偏左，右侧留空，后续子模式可横向追加，不改布局） |
| 不参与 | 关卡卡编号、前置解锁链、「通关数 x/4」统计、`WBP_LevelCard::SetData` 的关卡字段 |
| 复用 | 只复用视觉语言（`T_UI_CardRound` 九宫格 + 同一套字号/颜色 token），**不复用** `FLevelEntry` 数据模型 |

### 0.4 三态定义

| 态 | 触发条件 | 视觉 | 交互 |
|---|---|---|---|
| 未解锁 | `UNaiwaProgressSubsystem` 中 **不存在 1-1 的通关记录**（含全新存档） | 立绘降饱和 + 明度 60%、右上角锁图标、副标题显示解锁提示 | 可点 → 只弹 1 行提示「先过 1-1」，**不进图** |
| 可进入 | 1-1 已通关，且 `UNaiwaP4SaveGame.bRunCleared == false` | 立绘原色 + 呼吸微光 | 点 → 进 P4 第 1 章 |
| 已通关 | `UNaiwaP4SaveGame.bRunCleared == true`（读 P4 独立槽） | 金色描边 + 左上角「已通关」角标 + 最佳用时/最高连击 | 点 → 进第 1 章开新一轮（局内卡清空，**不动**历史最佳） |

### 0.5 点击后流程（推荐 A）

**A（推荐）：直接进第 1 章，不做章选页；章内逐章推进，死亡只回本章入口、保留已抽强化。**

理由一句：单局 28–36 分钟是一条**连续的强化曲线**（每章 3 选 1、共 9 次抽取，决定终局 DPS 与 Boss 是否超时），任何章选 / 跳章都会切断曲线，让 §3 的 DPS 校验失效。

**否掉的三条**：B 先开章选页（要维护 10 个进度位，与「抽取次数 = 通关章数」冲突）／C 十章一次性解锁（前 3 章冲撞·大笑·防御教学失去意义）／章节内检查点（Boss 战失去压力，见 §11 问题 4）。

### 0.6 与其他子模式的关系（一句话）

**不共享关卡进度、不共享存档槽、互不影响，只共用奶蛙资产** —— 进度写自己的 `UNaiwaP4SaveGame`（独立 slot），P1/P2/P3 的 `UNaiwaSaveGame` 一个字节都不改；唯一跨界读取是 `IsUnlocked("1-1")`（**只读**，仅用于解解锁门）。

### 5.1 二阶段 / 锁血语义（HUD 与战斗逻辑共用同一条规则）

**二阶段不是锁血。** 两者是两套机制，必须分开实现：

| 机制 | 触发判定 | 血量 | 无敌 | 溢出伤害 | 解除 |
|---|---|---|---|---|---|
| **二阶段** `phase2_at` | `hp ≤ ceil(maxHp × at)`，首次向下穿越 | **不钳制**，roar 期间照样按伤害掉 | roar 期间**全场无敌**（1.35–1.7 s，按 Boss 表 `roar_s`） | roar 期间受伤无效，**丢弃不累计** | roar 结束，伤害 ×1.25、招式表扩容、清一次敌弹 |
| **锁血** `hp_lock` | `hp ≤ ceil(maxHp × at)`，首次向下穿越，**且该锁未触发过**（每把锁一局只触发一次） | **钳制在 `at` 对应的整数血量**，锁定期间不可再降 | 锁定期间**无敌** | **丢弃，不累计、不溢出到锁后** | `hold_s` 读秒结束 → 清敌弹 → 恢复可受伤、可继续掉血 |
| **终局对拼** `final_mash`（章 10 · 10%） | `hp ≤ ceil(maxHp × 0.10)` | 钳制在 10% | 双方无敌 | 丢弃 | 7.6 s 结束：赢 → Boss 直接归零；输 → 玩家 HP 置 1，Boss 回到 10% 继续（**同一局不再触发第二次**） |

**单次伤害穿越多个阈值**（例：大笑带「笑到打嗝」92 伤把 Boss 从 22% 打到 12%，跨过 20% 锁血线）：**只触发最靠上（最先到达）的那个未触发阈值，其余阈值保持未触发状态，剩余伤害全部丢弃**。不允许"一穿到底连跳两个锁"。

**HUD 契约**：Boss 血条在 `phase2_at` / `lock_at` 位置画固定刻度；锁定期间血条冻结并在刻度上叠 1 圈读秒环（剩余 `hold_s`）；锁解除时血条抖动 1 次提示"可以打了"。

**三条补充定义（工程最容易踩的坑）**：
1. **倒计时从哪一帧开始**：从"这一笔伤害结算完成、血量被钳制的那一帧"起算，HUD 读秒环该帧值 = `hold_s`，之后每帧递减。不从动画事件回调起算（动画有 0.1–0.2 s 混合，会导致 HUD 和逻辑差帧）。
2. **锁血期间能否打进下一阶段：不能**。血量被钳制且伤害丢弃，阈值无法被穿越；若某 Boss 的锁血线低于二阶段线（B3 的 30% 低于 40%，且二阶段必先触发），顺序天然成立。
3. **解锁瞬间清弹幕**，且清弹幕发生在"恢复可受伤"之前同一帧内完成（先清场再开门），避免玩家在弹幕里被解锁瞬间打死。

### 6.1 抽取可解性（确定性规则，工程照此实现）

**先给结论**：9 次抽取、池 15 张，最坏阻塞 2 张（`thick_skin_2` 前置未满足 1 张 + 互斥剔除 1 张），第 9 次抽取时候选仍 ≥ 5 张，**正常情况永不缺 3 张**。下面这套是保底梯子，不是主路径。

| 步 | 条件 | 动作 |
|---|---|---|
| S1 | 恒真 | 候选集 `C = 池 − 已选 − 互斥剔除 − 前置未满足`（`thick_skin_2` 仅在 `thick_skin` 已选时进 C；`laugh_tooth` 与 `laugh_burp` 取其一后另一张永久剔出） |
| S2 | `|C| ≥ 3` | 对 C 做 Fisher–Yates，取前 3。**种子 = `run_seed XOR (chapter_index × 0x9E3779B9)`**，`run_seed` 为 32 位整数、随存档落盘 → 可复现、可回放。**首抽保护**：第 1 次抽取若洗出的 3 张不含 `fatter_ball` / `quick_nip` / `two_balls` 任一张，用 C 中按洗牌序最先出现的那张替换第 3 格 |
| S3 | `|C| == 2` | 展示这 2 张 + 补 1 张 `fallback_ball_plus`（若已有 2 次保底卡，则把 D1+D2 合成**连体卡**「奶皮厚了 + 更厚」补入，占 1 次抽取、同时获得两张） |
| S4 | `|C| ≤ 1` | 展示 C + 用 `fallback_ball_plus` 补到 3 张（同 id 最多出现 2 次，第三格允许重复） |
| S5 | 前置死锁兜底 | 若某张卡因前置永远拿不到（理论上 S3 的连体卡已覆盖），一律以连体卡形式出现，**不允许把卡变成不可获得** |

**工程契约**：`C` 的计算与洗牌必须走同一函数，禁止在 UI 层再随机一次；`fallback_ball_plus` 每次叠加累加进 `ball_bonus` 存档字段，单发伤害结算读 `(12 + card_flat + ball_bonus) × volley_factor`；`volley_factor` = 有一口俩 ? 0.75 : 1.0。

## §5' α 里程碑与三张锁定卡的关系（回应工程侧）

**α = 3 张卡的竖切**，卡池锁定为 **跳弹奶球（子弹）+ 肚子更圆（冲撞）+ 憋不住（大笑）**，不许替换。三张卡恰好各验一条核心链路：弹道二次索敌（B1）、充能格数 HUD + 硬直叠加（C1）、受击 → 能量 → 大招的闭环（L1）。

1. **α 的 Boss 取「奶桶冲锋 + 桶盖砸地」两招**（B1 简化版，2 招），覆盖竖切要验的三件事：预警渲染、Boss 血条 + 锁血刻度、阶段切换；也承载章 4 的两个教学点（撞墙硬直窗口 / 预警圈读条）。β 接正式章不用重做动画。
2. **不建议把章 1 第 5 波改成"小 Boss 化精英"**。章 1 的意图是"零压迫学会走位与连发"，插入任何血条单位都会打断教学节奏；且章 1→4 之间有三个教学节点（冲撞 / 大笑 / 防御），提前给 Boss 会让章 4 的"第一次预警读条"失去新鲜感。如 α 必须走正式章表，把 B1 简化版挂在独立测试图 `L_P4_AlphaBoss` 里，数据读 B1 的 DataTable 行、`chapter_id = 0`，与正式章表零耦合。
