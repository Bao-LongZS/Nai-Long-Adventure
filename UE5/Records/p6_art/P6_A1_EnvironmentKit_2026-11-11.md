# P6 A1 院落模块灰盒推进记录

日期：2026-11-11（Asia/Shanghai）  
范围：环境资产包与 14 个 M2 点位映射  
状态：**可审阅源块候选；没有导入 UE 或替代关卡灰盒。**

## 本轮交付

- 新增由 112 个 OBJ 组构成的院落灰盒；几何计数为 1,640 个顶点、1,587 个面、16 个预览材质。几何以厘米表示，Z-up，中心地面为原点。OBJ/MTL 可编辑，不含最终 UV、法线、碰撞或 LOD 设置。
- 新增 12 类环境模块干净不透明评审板（v02；旧 v01 保留）、两张世界空间软件投影视图、两张精确 M2 相机公式软件投影视图、自包含 A1 总览，以及从 MTL 自动生成的 16 色样表。视图从源 OBJ/MTL 重生成，深度缓冲已避免大地面错误盖住道具；它们不是实时引擎截图。
- 新增两张按当前 M2 点位图 1920×1080 正交投影公式制作的模型审阅图，叠加 14 个 Actor 锚点序号，辅助看真实比例和建筑轮廓关系。
- 新增 `P6_A1_PointPropAlignment_v01.json`，将 14 个当前 M2 Actor ID 分别映射到候选模型组或 A2 直接图录角色源图。11 个道具候选在 XY 与当前 M2 Actor 锚点一致，三名 NPC 共用图录 046/037 候选。
- 新增完整屋顶/临时剖切两份逐点深度代理 JSON，记录每个 pivot 的最近表面模型组，供后续定点看树冠、建筑和自身底座/桌面遮挡。
- 以两份 JSON 自动生成 14 点 M2 遮挡矩阵 SVG，将空间阻挡候选与自身几何/pivot 高度的诊断分开展示。
- 为对齐 M2，移动井/桶组到 `[2520,-2240]`，补入 G5 花束和可跳过笑点 Socks 的小檐架；以上仍需关卡设计确认外观和最终摆位。
- 新增 A1 handoff 与 SHA256 manifest，并更新 P6 SourceAssets README 和美术计划。

## 评审观察

完整屋顶图能看清院墙、门洞、戏台、房屋、井、奖杯、公告栏、检测仪、相机桌、巡夜簿桌、花束、晾衣绳、袜子与其余可选道具的几何关系。剖切图让点位覆盖更容易检查，但目前只是评审辅助。房屋/戏台屋顶仍会遮挡局部内院；固定 3/4 镜头、三点样片、行走路线和实际 UI/Billboard 遮挡还未核验。灰盒小道具轮廓简化，截图中花束和文字承载面需要后续尺寸/细节处理。

M2 镜头投影的简易软件深度比较显示完整屋顶时有 4/14 个 Actor pivot 点、临时移除屋顶/檐口后有 5/14 个 pivot 像素无遮挡。逐点报告发现，有些标记最近表面是点位自家部件（例如奖杯脚座、假花盆、巡夜簿桌面、垃圾桶盖、井水面）；更明确的空间遮挡候选是 Noticeboard 与树冠、Detector/PhotoTable 与房屋、NaiPai 与房屋/附近盆栽。这个区分用于指导 Editor 检查，不是可见率结论；Actor bounds、billboard 轮廓、点选面和实际 3/4 相机仍需在 UE 内复核。

12 件模块概念接触表 v01 的透明边缘含色边和孤立杂点。一次保持透明背景的清理未稳定去除，随后改制统一暖灰实底的 v02 评审板后边缘已干净。v02 仍只作形体方向参考，不拆正式贴图或单件资产；灰盒由独立程序几何搭建，没有从概念图片自动抠图或贴图。
