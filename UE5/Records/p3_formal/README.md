## 体验反馈落实

- 读取项目设置里的放弹间隔，默认 0.4 秒；HUD 显示间隔和当前冷却。
- 特殊道具、金蛋、传送和教学事件显示短时明确提示。
- 炸弹引线脉冲增强，爆炸增加亮度更明显的屏幕闪光和按距离衰减的短促镜头震动。
- 3-1 只显示基础炸弹；3-2 小地图按战争迷雾显示可见、已探索与未探索区域，并标记玩家、可见敌人、炸弹、金蛋和出口。
