# P3 正式关卡实现记录

更新时间：2026-10-27（Asia/Shanghai）

## 设计基准

- 3-1《第一夜》使用固定 11×9 教学布局，完整显示地图，不使用战争迷雾；3 枚金蛋中 1 枚藏在可破坏木箱里，(5,2) 的道具木箱必定提供教学道具。
- 3-2《奶察总局》使用 23×17 可复现种子布局，默认启用战争迷雾。
- 两张关卡各自有正式地图资产；既有 `L_NaiwaP3_M2ScenarioTest` 保留作体验存档与回退基线。
- 玩家视角跟随角色并放大，3-2 通过小地图查看全局布局。

## 地图材质

本轮地图贴图以新的独立 v2 资产提供：深蓝拼接石板地面、粗粝蓝灰石材、暖色旧木板箱。每格使用确定性的旋转变化降低重复纹样的感觉；原始贴图保留，老贴图也继续导入。

- 源图：`../../SourceAssets/P3/Tiles/T_P3Floor_A_v2.png`
- 源图：`../../SourceAssets/P3/Tiles/T_P3HardStone_v2.png`
- 源图：`../../SourceAssets/P3/Tiles/T_P3WoodCrate_v2.png`
- 生成方式：Codex ImageGen 新图生成；分别要求俯视、夜巡冷色石材或暖旧木、可平铺、无额外道具。

## 正式关卡生成

运行 `UE5/prepare_p3_formal_maps.ps1` 编译编辑器目标并通过 Unreal Editor Python 创建：

- `/Game/Naiwa/P3/Maps/L_NaiwaP3_31`
- `/Game/Naiwa/P3/Maps/L_NaiwaP3_32`

3-2 正式地图从当前场景化体验地图复制，保留既有布局预览与出生点；3-1 根据冻结参数新建固定教学图。源设计图和参数 JSON 存在 `design_reference/`，生成结果记录在 `formal_map_build_report.json`。

## 体验反馈落实

- 读取项目设置里的放弹间隔，默认 0.4 秒；HUD 显示间隔和当前冷却。
- 特殊道具、金蛋、传送和教学事件显示短时明确提示。
- 炸弹引线脉冲增强，爆炸增加亮度更明显的屏幕闪光和按距离衰减的短促镜头震动。
- 3-1 只显示基础炸弹；3-2 小地图按战争迷雾显示可见、已探索与未探索区域，并标记玩家、可见敌人、炸弹、金蛋和出口。
