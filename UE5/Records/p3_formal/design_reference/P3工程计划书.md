## 三、玩法系统规格

### 3.1 网格与地图生成

- 网格即世界：所有逻辑（移动、爆炸、AI、机关）都在整数格上，实体位置 = 格中心插值，**不使用物理引擎**
- 3-1：**手工固定布局**（教学必须确定性，不走种子）
- 3-2：种子生成，`seed = 关卡ID × 10000 + 尝试次数`；同种子必同图
  - 预制区块拼图（6 种：L 形掩体 / 十字炮台 / 长廊 / 开阔区等），坦克大战式地标
  - 软砖铺设率 ≈ 40%，其中 20% 为道具砖
  - 生成后跑 **BFS 连通性检查**，不可达软砖区强制打通（安全网，必做）
  - 出生点周围 3×3 强制空地

**生成与验收约定**：3-2 的 `levelId=32`，首轮 `attemptCount=0`，即首个候选 seed 为 320000；只在地图校验拒绝候选时递增 attemptCount，玩家按 R 重开沿用当前 seed。随机流按 `map / loot / scripted_ai` 分离并由主 seed 确定初始化，不能因一次掉落额外消耗地图随机数。BFS 把硬砖视为阻断、软砖视为可挖通成本、传送门视为成对图边；踩板可达后开放对应金库门。校验出生点到所有目标蛋、两块踩板和出口可达；候选失败时按固定顺序重抽，最多 64 次，仍失败则将可破坏软砖改为空地并复检，硬墙造成的断连继续拒绝。

### 3.2 炸弹系统（五蛋五弹）

| 奶蛋 | 炸弹形态 | 定位 |
|---|---|---|
| 奶蛋（白） | 标准十字，威力=格数 | 基础款 |
| 豆奶 | 大十字，威力 ×1.9 | 清场拆大片砖 |
| 奶茶 | 圆形径向（半径 2，不穿砖） | 狭道拐角神器 |
| 奶鼠 | 分裂 3 枚小弹滑向相邻空格 | 布雷区 / 连锁事故之王 |
| 奶鸡 | **不是炸弹，是道具**：跳一格（跳过炸弹/敌人/洞），8s 冷却 | 对抗核心 counter |

- 放置 → 2.5s 引爆 → 火焰被硬砖/未破软砖挡住（软砖毁后火焰不穿透）
- 连锁：火焰触弹 → 0.2s 逐个引爆
- 成长：初始 1 枚/威力 2 → 道具可堆到 3 枚/威力 4
- 哑火彩蛋：2%（种子决定）延迟到 5s 才爆

**固定逻辑与事件顺序**：逻辑以 0.1 秒整数 tick 推进，移动在格心间插值；炸弹 25 tick 引爆，连锁在首次命中后 2 tick 引爆，火焰保留 3 tick。每 tick 固定处理：玩家移动提交 → 奶察巡逻决策 → 到期炸弹按格索引/放置序号排序并逐个解析（破坏软砖立即生效且该条火线停止）→ 连锁计时 → 统一伤害 → 火焰过期。相同 tick 里的输入按玩家控制器接收顺序记录；AI 路径平局按上、右、下、左排序。

### 3.3 机关（5 种，全纯网格逻辑）

1. **奶瓶传送门**（成对）：踩入传送，2s 冷却
2. **踩板开关门**：踩住开门，松脚 1.5s 缓关（可钓鱼引 AI 踩板）
3. **尖刺格**：3s 周期弹出，弹出时伤害；**会把放在上面的炸弹提前顶爆**
4. **奶流传送带**：推动玩家/道具/小炸弹（运弹 = 遥控布雷）
5. **断裂地板**：烧两次 → 1s 后塌陷成洞 10s（洞吞火焰，可销毁失误布雷）

### 3.4 敌人 AI（统一状态机，五参数差异化）

骨架：`PATROL → ALERT → CHASE → SEARCH → RETURN`

| 敌人 | 移速 | 视野 | 炸弹态度 | 特殊行为 | 威胁 |
|---|---|---|---|---|---|
| 奶察 | 0.8× | 4 格 | **避爆区** | 巡逻路线固定 | ★★ |
| 奶杀 | **1.1×（比玩家快）** | 5 格 | 无视直冲 | 被软砖挡路会就地开炸开路 | ★★★★ |
| 奶豪 | 驻守 | 3 格半径激活 | 剧本扔弹 | 砸砖守宝；砸开的墙帮玩家开路 | ★★★ |
| 奶雨 | 驻守高点 | 6 格 | — | 8s 一发减速泼洒，近身瞬移（**可砍**） | ★★ |

**奶察真评估原理**（每 0.2-0.5s 规划节拍，非常驻）：
1. 遍历场上炸弹 → 算爆炸范围 + 剩余秒数 → 写入危险表（每格=几秒后有火焰）
2. BFS/寻路把危险表当代价（火焰到达前过不去的格 = 墙）
3. 无安全路径 → FLEE 向远离爆区方向
- 21×15 网格重算开销≈0；**贵在调参**（目标：大部分时候聪明，偶尔上钩——玩家陷阱要骗得到它）

**对抗性双 MVP**：① AI 也抢道具掉落（FETCH 目标，捡到自己用） ② 敌人炸改地形（奶杀开路）

### 3.5 道具经济

掉落权重（道具砖炸开掉落，独立种子流保证同种子同顺序；原设权重合计 105，运行时按总权重归一化）：
炸弹上限+1（25%）/ 威力+1（25%）/ 奶鸡跳（15%）/ 速度+15%（15%）/ 奶罩护盾挡爆炸不挡抓捕（10%）/ 透视 3s（10%）/ **混乱奶反向操作 3s（5%，阴间陷阱）**

三条 build 路线：威力流（怕自爆）/ 数量流（怕奶杀突脸）/ 机动流（怕狭道泼洒）。

### 3.6 有限视角（战争迷雾）——仅 3-2

- 全图默认不可见；玩家周围 **6-7 格**可见；**视野被墙遮挡**（BFS 可见集，拐角后看不到）
- 走过区域保持**半亮记忆**（地形记得住，敌人/道具不显示）
- 狂暴逃亡阶段视野扩到 **10 格**；爆炸瞬间全屏闪照 0.3s
- 实现：网格可见集 + 一张遮罩材质，约 1-2 人天
- 设计意图：奶杀从迷雾扑出 = jump-scare 喜剧 + 阴间音效最佳触发器

### 3.7 局内流程

`开局出生 → 探图拆砖 → 收集金蛋 →（3-2）集齐触发全场狂暴提速 30% → 走到出口 → 结算`
死亡：3 命耗尽 → 结算重来（种子同图）。一局目标 2-4 分钟。

### 4.1 · 3-1 教学「第一夜」（11×9，手工布局）

设计原则：一条动线把全部基础机制教完，**结构上不会死**（奶察 ×1 且 0.5× 速）。

```
列 0-10 × 行 0-8（行 0 在北）。硬砖棋盘骨架，软砖手工摆。
S=出生  E=出口  ◎=金蛋  P=传送门对  D=道具砖  C=奶察巡逻路径
```

| 段 | 区域（行） | 教什么 | 强制编排 |
|---|---|---|---|
| ① | 南区（行 6-8） | 放弹 + 炸软砖 | 出生 3×3 空地，东侧留一条纯软砖走廊，炸开才能前进 |
| ② | 中南区（行 4-6） | 危险认知：自伤 | 摆一个「贪心陷阱」：道具砖两侧是死格，玩家必须炸完绕行，站原位会被自己下一颗弹炸到（教学位不受伤，只弹提示） |
| ③ | 中区（行 4） | 道具拾取 | 1 块道具砖（保底出「炸弹上限+1」） |
| ④ | 北区（行 1-3） | 传送门 | 一对传送门跨过一道全硬砖墙——不传送无法到达北区深处 |
| ⑤ | 东北角 | 收集 + 出口 | 金蛋 ◎×3（①②④段各 1 枚），出口在最后金蛋旁边 |

- 奶察巡逻路径：北区一条固定 8 格环线，与玩家动线只交叉 1 次
- 本关**无迷雾、无狂暴、无奶杀/奶豪**
- 时长目标 60-90 秒

### 4.2 · 3-2 闯关「奶察总局」（23×17，种子 + 分区）

空间分层（难度按离出生点距离递增）：

| 区 | 位置 | 内容 |
|---|---|---|
| 外环 | 距出生 0-6 格 | 奶察 ×2 巡逻；软砖率 45%（好炸）；金蛋 ×1 |
| 机关带 | 6-10 格环带 | 全部 5 种机关成组出现（传送门对×2、踩板门×2、尖刺走廊×2、传送带×1 组、断裂地板×1 片）；金蛋 ×2 |
| 中心金库 | 半径 4 格 | 硬砖厚壳 + 踩板门守卫；奶豪 ×1 + 奶雨 ×1（若奶雨被砍则双奶豪）；金蛋 ×2 |

- 敌人配置：奶察×2 + 奶杀×1（外环游走）+ 奶豪×1 +（奶雨×1）；**奶杀放在外环与机关带交界**——玩家刚学会 basics 就遭遇「比我还快」的东西

- 出口：出生点附近（狂暴是回程跑，动线天然形成「去远回近」的节奏弧）
- 调参预留：软砖率 / 敌人速度 / 迷雾半径全部进配置表，试玩周集中调

## 五、技术架构（UE 5.8.3）

### 5.1 模块划分

运行时测试地图先使用独立 `L_NaiwaP3_M1Prototype`，地图 GameMode 单独覆写，不改全局 P1 默认地图。`UE5/run_p3_m1.ps1 -Mode SelfTest` 用 Editor-Cmd 加载此地图并运行无界面冒烟回归，输出 `NAIWA_P3_M1_PASS` 或首个失败条件；`-Mode Play` 通过 Editor 的 standalone game 启动可玩的 M1 沙盒。Game target 已编译，但未Cook的编辑器新地图应由 Editor-Cmd 加载，不直接从裸 Game target 查找地图。

### 5.2 渲染方案（夜巡风格落地）

- **正交相机 90° 朝下**，格子在屏幕上是正方形（爆炸范围零偏差）
- 砖块/地面/机关：**Unlit 材质**，颜色和纹理规范以关卡参数 JSON 为单一来源；石砖用低对比刻痕，软砖用木板与 X 形斜撑，地面用细石板压纹。出口使用青绿色门洞与外向箭头，金库门使用钢蓝圆形转轮，图标和图例名称明确区分；不用外部素材贴片或动态灯光
- 角色：**Paper2D 精灵 + billboard**（每帧朝向相机），脚下 Decal 椭圆影子
- 爆炸：网格驱动的十字/圆形精灵，缩放+淡出，无粒子物理
- 迷雾：全屏遮罩材质，按可见集纹理更新

### 5.3 可复现性规范（铁律）

1. 一切随机走 `seed`，禁止 `FMath::RandRange` 裸调用；运行时以 `FRandomStream` 封装 `P3Rand(stream)`，各流独立初始化
2. 逻辑 tick 固定为 0.1s；AI 固定 tick 运行，玩家/敌人只在逻辑格心之间插值表现
3. 禁止任何 `SimulatePhysics`；实体位移 = 网格插值
4. 每次自动化测试输出 `seed → 地图哈希 → 事件序列哈希`，回归可对比；M1 固定图也输出地图哈希
5. 事件排序、炸弹火线阻断和同 tick 伤害顺序按 §3.2 约定实现，任何改动更新回归 fixture

### 5.4 输入

- 键盘：方向键/WASD 移动，`Space` 或 `J` 放弹，`Shift` 奶鸡跳（持有道具时）
- 与 P1 键位习惯（D/A/Space）在文档层面提示差异，进 3-1 开场做 3 秒键位提示
- 手柄：预留映射，本轮不做验证（沿 P2 遗留待办）
