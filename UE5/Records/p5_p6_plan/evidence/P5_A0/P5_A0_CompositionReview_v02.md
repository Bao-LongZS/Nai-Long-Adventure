# P5 A0 画幅与游戏构图评估 v0.2

日期：2026-10-28（Asia/Shanghai）

## 当前结论

**画幅比例适合 16:9 游戏窗口，元素分配作为概念图成立；当前角色/障碍相对位置还不宜直接冻结为实际关卡镜头。** 项目所有者于 2026-10-28 通过 v02 和角色首稿，并授权继续美术生产。v02 保留 v01 构图与角色，只修正了偏亮、偏电蓝的色调。Editor 路线 fixture 检查仍是集成验收项。

## 画幅与元素占比

- v02 画布为 1672×941，比例 1.7768；16:9 为 1.7778，差约 0.05%，缩放到 1920×1080 或 1280×720 不会产生有意义的裁切。
- 像素色域估算的角色+雪板范围约为画宽 14.3%、画高 18.6%，中心约在 X=54.4%、Y=61.1%。投影到 1280×720 约 183×134 px（含雪板），基本轮廓能读；绿虹膜、扁三趾等身份细节仍需在实际 720p Sprite 尺寸下核验。
- 雪坡占据画面下半部，玩家落在坡面上，前中远景关系清楚。上下空间够放跳跃姿态，当前构图不需要为了 16:9 另行裁切。
- 四个 HUD 占位分布在两侧上角，中间视野留空。面板高约画面 11.7%，合计约画面 5.2%；投影到 720p 面板高约 84 px。里程、gap、金币、连击分开，布局可继续作为方向稿。

## 实际游玩视距风险

P5 规格暂定 1920×1080 下 1000 uu ≈ 1510 px，因此全画面横向视野约 1272 uu（12.7 m）。按 v02 角色中心约 54.4% 估算，角色前方直至右屏边只有约 5.8 m，即基准 15 m/s 时约 0.39 s。图中最近雪岩约从画面 77% 处开始，距角色投影约 2.9 m，即约 0.19 s。

这些数值来自合成概念图的屏幕位置，不是路线或碰撞距离；不能直接作为关卡数据。但它暴露出构图风险：若照当前相对位置把雪岩当成第一个真实障碍，玩家几乎没有观察和起跳余量。

建议 Editor 样片把玩法锚点先放在画宽约 40–42% 再对照 fixture，或由工程提供更早的坡形/障碍预告；保留屏幕中心偏右的决定也可以，但需明确增加视野/提示方案。该决定影响镜头基线，进入正式路线前由项目负责人确认，不在本轮概念图中擅自改动。

## v01 → v02 色调调整

采用 v02 作为当前色调评估图：整体亮度观感压低，雪面保留暖白纹理，天空与远山蓝色更克制，阴影层次保留。HUD 暂沿用原稿强对比，因为危险 gap 需要快速识别。

全图像素统计仅作版本对比，不等于显示器校色：平均 HSV 饱和度由 116.2 降至 76.0；HSV 明度均值由 225.3 降至 197.9；RGB 三通道都不低于 245 的近白像素由 2.05% 降至 0.13%。平均线性加权亮度近似保持在 164 左右，主要变化是降低极亮区域并压低蓝色饱和感，而非把画面整体压暗。

## 放行边界

可继续用 v02 做 A0 方向稿；尚不能判定游戏构图验收通过。待真实 Editor 样片用 1000 uu / 185 uu 标尺、坡面碰撞、实际角色 pivot、障碍位置与 1920×1080/1280×720 截图复核，特别记录玩家前方可见距离。当前概念图不是分层背景、关卡路线、碰撞图或性能证据。
