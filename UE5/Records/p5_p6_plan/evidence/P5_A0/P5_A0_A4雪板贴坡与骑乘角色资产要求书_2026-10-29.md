- 主角奶蛙与袋鼠坐骑始终是两个独立角色层；骑乘时奶蛙保持可见，袋鼠不替代玩家角色。

- 继续使用清晰侧视、面向世界 `+X`（画面向右）的 2D 透明素材，适配当前 P5 侧卷镜头。

## 姿势与锚点约定

- `Glide` 4 帧：循环中有细微重心、手臂、膝盖和雪板压力变化；循环首尾姿态/重心连续，不能四张近乎相同的静图。
- `Preload/Takeoff` 3 帧：压低蓄势 → 最大压缩 → 离雪释放，表现有明确先后和重心上抬。
- `AirTuck/Extend` 3 帧：离地收身 → 稳定收身 → 伸展准备落地；不带雪板，板由独立层跟随锚点。
- `AirTurn` 3 帧：躯干/四肢有反向平衡与转体跟随；完整转角仍由工程连续旋转角色/板层，不绘制多张重复的 360° 方向帧。
- `Land/Recover` 3 帧：板面接触 → 屈膝吸收冲击 → 回到滑行重心；冲击前后不能硬切。
- `Fall/Recovery` 4 帧：失衡 → 接触雪面/翻滚 → 支撑起身 → 恢复滑行；方向明确，末帧可自然接回 Glide。
- `Ride` 3 帧循环：奶蛙坐/蹲在袋鼠鞍座上，重心随坐骑轻微起伏并持续抓握/平衡；奶蛙仍独立放在 A4 层，不画进袋鼠图。
- 全部动画以独立计时器/游戏状态事件按帧时长播放，不能依赖渲染帧率逐帧推进；循环首尾连续，状态切换使用明确过渡帧或可读的匹配姿势。
- 雪板接触线以板底为准，板中心枢轴置于几何中心。姿势图不预烘焙 ±15°/±30° 坡度版本，工程通过独立板层旋转处理。

## 生成提示词参考

> 沿用已确认的 P5 奶蛙与美团袋鼠参考造型，制作清晰、统一描边和材质的 2D 侧视游戏角色图集。画面朝右（世界 +X），透明背景，保持角色比例、色彩和面部特征。奶蛙身体与雪板必须完全分层：奶蛙图层不画雪板，雪板独立为透明侧视图，板头朝右并留出中心旋转枢轴。增加一帧奶蛙自然坐/蹲在袋鼠鞍座上的骑乘姿势，奶蛙与袋鼠分开输出，骑乘组合中两者同时完整可见。仅输出干净角色/装备轮廓，不要场景、雪花、阴影、文字、边框或透视夸张。

## 验收条件

- 每格无相邻姿势残片，透明边缘无白色/蓝色杂边；atlas 格子尺寸一致，姿势不会越格。
- A4 各动作帧均不含雪板；A5 坐骑不含奶蛙；Ride 序列可独立叠放到袋鼠鞍座，坐骑运动与奶蛙重心关系稳定。
- 每段连续播放可读为动作，而不是快速闪换状态卡片；正常播放 8–12 fps（依动作调整），切段时不跳位、不骤变尺寸，滑行/骑乘首尾可无缝循环。
- 以雪板中心为枢轴旋转到 `-30°、-15°、0°、+15°、+30°` 时，板底轮廓连续、脚部仍接近板面；无需身体随板角整体倾斜。
- 提供 anchors JSON 和源文件；不在 PNG 上绘制坐标或说明文字。
