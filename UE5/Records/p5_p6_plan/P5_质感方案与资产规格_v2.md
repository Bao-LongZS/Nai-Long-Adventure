# 第 4 关 · 质感方案与资产规格 v2

日期：2026-10-28 · 状态：**全量 B 已由项目所有者拍板**  
适用：P5 工程计划书 v2（玩家可见关卡 4-1）。本版取代 v1 中“7–9 张”与“16 项/26–30 图”混用的清单；v1 仅保留历史参考。

## 1. 目标与决策边界

目标是达到用户选定的全量手绘厚涂视觉，同时保持雪坡几何与碰撞同源。**全量 B 是本关生产范围**：手绘三层背景、雪面/障碍/袋鼠/特效、主角材质与姿态、完整材质融合和 UI。B- 的 9 张背景包只作为旧版本比较，不进入当前交付范围。

全量 B 的原型参考是用户提供的滑雪预览：三层背景、连续冷暖雪坡、清晰角色姿态、左侧雪崩墙和图形 HUD。生成图里的前景景深虚化和误标金币/gap 不作为目标；正式游戏需保持场景清晰并使用独立的距离、金币、连击 UI。

## 2. 渲染/坐标基线

- 固定侧视正交相机；1920×1080 作为主要标定分辨率，1280×720 作缩放回归。
- 远/中/近景分别以相机位移的 0.12/0.30/0.65 倍跟随；雪坡碰撞几何独立存在，背景图片不参与碰撞。
- 所有资源使用 Unlit/半透明或 Masked 材质；不依赖实时灯光、PBR、体积后处理或运行时阴影。
- SnowGround UV 与路线段对齐；连续路线只能更换贴图坐标，不拼接独立平面造成碰撞缝隙。
- 颜色由 `Palette_L4` 单一色板表驱动；暖色只用于金币、门板和明确的交互物。4 层明度：远景最低对比、近景可读、交互物最高对比。
- 遮挡排序顺序固定为：远景山脉 → 中景林线 → 近景雪脊 → 地形 → 角色/障碍 → 前景雪雾/雪崩墙 → HUD。

## 4. 渲染与导入规则

- 固定侧视正交；1920×1080 主标定，1280×720 缩放回归；三层视差系数 0.12/0.30/0.65。
- Unlit/手绘烘焙色调；不依赖实时灯光、PBR 反射、体积雾、景深或运行时阴影。雪面亮部/蓝紫暗部绘入材质/贴图，角色和障碍靠剪影与手绘明暗可读。
- 颜色 PNG 开 sRGB；遮罩/高度/特效强度用线性采样；颜色来自 `Palette_L4`。半透明资源验证预乘 alpha 边缘，避免白边/黑框。
- Atlas manifest 必须记录每帧矩形、播放顺序、脚底锚点和循环模式；动画帧不得在纹理压缩/过滤时串格。
- 前景和背景全画面保持清晰；若需要雪雾遮挡，只在雪崩/局部 VFX 层，不能用镜头景深虚化障碍。

## 5. 全量样片与出口门

全量生产前先完成一张真实 Editor 截图：三层背景、完整雪坡材质、主角三种姿态之一、树/岩石、雪崩墙、gap/HUD。通过以下门后批量制作余下变体：

1. 5 名评审中至少 4 名能指出雪面亮部、蓝紫暗部和坡面前后层次；结果用于方向筛查，不声称统计显著。
2. 角色立绘、雪板、脚底锚点、坡面碰撞、障碍剪影、雪崩亮边都能辨认；奶蛙与奶龙母体在角色视图中能明确区分，绿虹膜、浅腹部和深灰褐手掌/三趾脚掌在 1080p 与 720p 均可辨；场景与立绘笔触/光色统一，无三维渲染感、白边拼贴和景深虚化；关闭 HUD 后也能看清可玩面。
3. 1000 uu 横向尺与 185 uu 纵深尺按相机投影测量；截图实测值记录到 JSON，不把理论像素写成通过证据。
4. 视差层循环首尾无跳变；gap 20/40/60 m 至少三档截图能区分。
5. Editor 可见窗口 p95 ≤8 ms @1080p；未在可见 Editor 中测得前不报性能通过。
6. 预览图 HUD 在真实 UI 中分开显示里程、gap、金币、连击；“24 m”只能标雪崩 gap，不与金币图标组合。

失败时修订材质/构图/源图并重复样片门，不降回 B-。所有源图、图集清单、颜色表与导入报告入版控或版本化记录。

## 6. 预算与工作量

- 质感方案原估全量 B：10.5 美术人天 + 6 视觉工程人天，作为当前基线；低置信度 ±40%，现覆盖 19 PNG/40 帧、奶蛙 2D 六姿态立绘 atlas、雪景/特效和局部材质集成，不含玩法工程、真人试玩、音频制作和超出三轮的美术返工。六姿态是对原 3D 角色材质/姿态工作的替代范围，不叠加预算。
- P5 工程计划书中 25–34 工程人天已包含这 6 天视觉工程；P5 总体为 25–34 工程人天 + 10.5 美术人天，不能把视觉工程重复加一次。
- M1 样片若发现需增加超过六个奶蛙立绘姿态或重画角色比例，先更新估算与范围后再做该资产；不默认为已包含。
