# P5 美术执行计划 —— 第 4 关滑雪大冒险「奶蛙下坡」

日期：2026-10-28 · 状态：**全量 B 已拍板；A0 方向获准继续，Editor 样片出口门仍待验收；候选资产正在整理。**  
范围：P5（玩家可见 4-1），引用[全量 B 规格](P5_质感方案与资产规格_v2.md)；工程实现见[P5 工程计划](P5_工程计划书_v2.md)。

## 1. 目标与边界

交付同一笔触体系的 2D 手绘厚涂雪景、连续可玩雪坡、奶蛙六姿态立绘、袋鼠六帧立绘、雪崩/落地效果和可导入 UE 的源资产包。目标是让 1920×1080 与 1280×720 下都能一眼辨认奶蛙、坡面、障碍、雪崩 gap 和金币/连击反馈。

- 角色只用 2D 立绘和透明 atlas；不做 3D 奶蛙模型、SkeletalMesh、PBR 皮肤或模型渲染图。
- 雪坡可玩轮廓、碰撞和里程由工程路线数据生成；背景画不能代替地形/碰撞。
- 用户确认的 `player.png` 是奶蛙造型参照；`Big_Laugh.png` 是奶龙母体对照。奶龙不是奶蛙，母体考据 PDF 不作为奶蛙造型母版。
- 现有全量 B 预览仅为视觉方向图，不是实机验收，不计为生产贴图或 atlas 帧。
- 关卡专用雪山/树林/雪面图归 `UE5/SourceAssets/P5/`；只有确实跨关使用并验收的角色/通用 UI 源稿才放 `Common`。

## 2. 职责与输入

| 角色 | 责任 | 交付 |
|---|---|---|
| 2D Artist | 背景、雪面、障碍、角色/VFX 手绘 | 分层原稿、透明 PNG、atlas 源稿、帧锚点 |
| Technical Artist | 色板/导出规范、alpha、图集规格、材质参数与导入协作 | manifest、导入说明、检查截图/记录 |
| Gameplay Engineer | 可玩坡面、Sprite 帧切换、Unlit 材质、HUD 数据绑定 | UE 组件、碰撞/相机/排序、性能与回归证据 |
| Level Designer | 里程路线、镜头构图、安全空间、障碍摆放 | 路线 fixture、可读性点位和样片评审记录 |
| 项目负责人 | G1 样片出口门 | 确认笔触、比例、奶蛙身份特征和画面层次 |

输入冻结为：侧视正交、三层视差 0.12/0.30/0.65；Unlit/烘焙手绘色；不依赖景深、体积后处理、实时阴影；主角以透明 2D 立绘呈现；资产数量和尺寸以本包所附 P5 质感方案 v2 为准。

## 4. 生产阶段与出口门

| 阶段 | 内容 | 出口门 |
|---|---|---|
| A0 资产准备 | 建立 P5 目录、冻结尺寸/命名、确认相机/坡面空位 | 工程 fixture 和资产规格版本一致 |
| A1 样片 | 完成 A0，导入 Editor，与真实坡面、障碍和 HUD 占位同屏 | 按规格 v2 六项样片门检查；未过时修样片，不开批量制作 |
| A2 批量制作 | 完成 A1–A7 的背景、角色 atlas、障碍及特效 | 每类资产独立检查尺寸、透明边、可读性、色板与帧锚点 |
| A3 交付集成 | 完成 A8，向工程交付清单、源文件和报告 | 清单 19 PNG/40 帧对齐；工程导入路径/材质映射明确；缺失资源为 0 |

样片门沿用规格 v2：1920×1080 主标定与 1280×720 缩放检查；1000 uu 横向尺与 185 uu 纵深尺实测入记录；gap 20/40/60 m 可读；前景/背景不使用镜头景深；奶蛙手足深色面积在两种分辨率下可辨。1080p Editor p95 ≤8 ms 属工程/TA 实机测量门，不由静态 PNG 或本计划宣称通过。

## 5. 时间和任务依赖

可与工程 M0/M1 并行；A0 通过后再批量作画。P3 M2 不阻塞奶蛙新 atlas、P5 背景或本关灰盒；它只影响已有皮肤立绘是否可标记为 Common 复用。工程计划中的 6 个视觉工程人天负责 Sprite/材质/排序和场景接入，已经包含在 P5 的 25–34 工程人天内，不从本 10.5 美术人天重复扣/加。

开始日期不指定；排班必须按角色资源填入实际周次。建议顺序：A0 样片 → 角色与雪景并行 → 特效/manifest → Editor 集成验收。

## 6. 目录与命名

- 源稿、分层稿、贴图与图集源文件：`UE5/SourceAssets/P5/{Backgrounds,Characters,Environment,FX,Materials,Manifests}/`。
- 运行时导入件：`UE5/NaiwaP0/Content/Naiwa/P5/`；由工程/TA 导入，绝不把同一份 P5 源 PNG 放进 `Common`。
- 每个资产至少有 `AssetId`、版本、作者角色、来源、尺寸/帧、透明/色彩空间、导入设置、验收状态。命名和 atlas layout 依质感规格 v2。

## 7. 本计划不含

新增路线/天气、超过 6 个奶蛙姿态、袋鼠复杂动画、3D 角色、配音/音乐制作、多轮超范围返工、用户预览图的逐像素复刻。变更按开工包 README 的变更记录执行并重新估算。
