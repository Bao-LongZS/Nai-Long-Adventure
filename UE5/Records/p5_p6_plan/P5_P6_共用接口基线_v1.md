## 1. 单一数据源

本文件冻结两关共享的身份、货币、解锁和存档口径。P5、P6 计划书是工程验收合同；原始的《第4关/第5关提案 v3》和《第45关关联说明 v2》保留为创意来源，若与本文件冲突，以本文件及对应计划书为准。

不得让 P5、P6 各自维护一份角色/价格/解锁配置。工程实现使用同一份版本化数据资产（优先 DataTable 或 JSON 导入的 DataTable），并校验唯一 ID、价格、能力 ID 与引用资源。

## 3. 货币、解锁与存档

| 项 | 冻结口径 |
|---|---|
| P5 结算 | 票数 `floor(Score / 50)`；完赛与被雪崩吞没均按已得分结算；不因失败抹去本局得分 |
| P5 皮肤购买 | 奶雨 40、奶察 60、奶豪 80、奶杀 140；全收集价格 320。商店不出售升级或真实货币商品 |
| P6 解锁 | 完成一次 P5 结算即解锁 P6；包括冲线和雪崩吞没两种结算，避免新手被锁在门外 |
| P6 试用 | 首次进入 P6 可借用任意皮肤；本局最多切换两次，试用不登记为购买。解谜不以拥有皮肤为门槛 |
| P6 首通奖励 | 首次完成最高评级 120 票、次级评级 60 票；未结案不发首通票。奖励只记个人最高档一次 |
| P6 重玩奖励 | 完成结案后每次重玩固定 20 票；错误提交本身不发票。票数可用于 P5 重掷种子及贴纸 |
| 存档范围 | 奶票、已购皮肤、P5 最佳记录、P6 已收集证据/已结案评级写主存档；关卡运行状态与当前种子写局内/临时存档 |

## 4. 统一输入与 UX 边界

- P5：Space 跳跃；空中 A/D 控制旋转；Esc 暂停；R 长按 0.6 s 重开。文案中的“3 个键”指三枚玩法键 Space/A/D，不包括系统键 Esc/R。
- P6：WASD/方向键移动；鼠标或 Space 查看近处点位；Tab 换当前皮肤；F 显示/关闭对应信息层；Esc 暂停。线索板不在玩家提交答案前显示答案正确性。
- 选关页仍使用玩家可见的 4-1、5-1；衣柜是主菜单入口。P5 完成不要求购买皮肤才能进入 P6。
