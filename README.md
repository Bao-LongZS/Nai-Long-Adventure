# 奶蛙冒险 · Nai-Long-Adventure

一款横版闯关游戏。主角「奶蛙」是从网络形象「奶龙」二创来的，**不是官方作品**。

最早用 C++ / SFML 做过一版原型练手，现在主线整体搬到 UE5 重做。角色不是手捏的——用 Python 脚本在 Blender 里生成，所以造型能一条命令重来，每轮改动也都能回溯。

打开游戏就是第一关：从左边出发一直往右，跳过断口，踩弹跳板飞上高台，赶在缩回去之前冲过限时平台，来回按开关把移动平台召到脚下，路上还得躲开平时看不见、踩上去才现形的尖刺。出口不是走过去就完事——得先拿到指定的那颗拾取物。

摔死不用从头来。路上有 8 个检查点，掉下去就在最近的安全岸上原地复活，机关也一起复位。死亡画面是一段捧腹大笑的动画，音效按检查点分段换人声，单次闯关死到第 3 次会放一段更长的彩蛋。

想先看关卡长什么样，这里有一张 [关卡结构图](UE5/Records/关卡结构图_v7_20261018.html)；实际跑通的过程、每个检查点的复活、各种边界情况怎么处理，写在 [P1 工程报告](UE5/Records/P1_工程报告_20261018.md) 里，原始记录在 [验收证据目录](UE5/Records/p1_acceptance_20261018)。

**第二关还在纸上。** 奶蛋弹弓关，三小关——先斩首打掉前排、再选蛋（五种奶蛋各有脾气，一关只够带几颗）、最后综合考核，全程零余量。它不是一个新模式，是同一局的下一段：1-1 跑到终点淡出淡入，接着站到弹弓前，死亡次数和解锁的蛋种都带过去。可行性与工作量评估过一轮，见 [P2 工程计划书评估](UE5/Records/P2_工程计划书评估_20261019.md)。

## 怎么跑

需要 **UE 5.8**，脚本默认从 `C:\Program Files\Epic Games\UE_5.8` 找引擎，装在别处就加 `-Engine <路径>`。

```powershell
# 直接进游戏，全高质量、无垂直同步
powershell -File UE5/launch_p1_v7.ps1

# 改成在编辑器里打开
powershell -File UE5/launch_p1_v7.ps1 -Editor
```

也可以直接用 UE 打开 `UE5/NaiwaP0/Nai_Long.uproject`。

操作：`A` / `D` 左右走，`Space` 跳，`Shift` 切换走和跑，`R` 重开本关，`P` 或 `Esc` 暂停。走路和跑步速度差一倍，有些断口只有跑才过得去——这也是关卡设计的一部分。

**打包**：

```powershell
powershell -File UE5/package_demo.ps1                    # Development
powershell -File UE5/package_demo.ps1 -Config Shipping   # Shipping
```

产物落在 `UE5/NaiwaP0/Saved/DemoBuild*`，体积大，不进仓库。`-SkipBuild` 直接用现有二进制跳过编译，`-UseUBA` 打开共享编译加速（默认关掉，因为这台机器上它偶尔会写盘失败）。

**改角色模型**（需要 Blender）：

```bash
python NaiwaCharacter/build_naiwa.py --from-primitives
```

`.blend` 是产物，脚本和参数才是源。每轮迭代目录里都留着 `rebuild_command.ps1` 和 `parameters.json`，可以一条命令复建并自动校验哈希。

**编 SFML 原型**（早期那版，已经冻结不再动）：

```bash
cmake -S . -B out/build && cmake --build out/build --config Release
```

## 什么东西才进仓库

只有一条判据：**删掉它，能不能用一条命令重新得到？** 能，就不进。

- 引擎缓存和构建产物（`Saved/` `Intermediate/` `Binaries/` `DerivedDataCache/`）—— 能重建
- 超过 1 MB 的中间数据（逐顶点 dump、npz、切片样本）—— 能重算
- FBX —— 能由对应 `.blend` 重新导出，本身还是种有损格式，留着只会让人误以为是源
- 生日视频产线 —— 含第三方音频素材，单独冷备，不进这个库

反过来，`.blend` 工程、UE 的角色 `.uasset`、音效原始 wav、验收报告和录像属于**唯一源或交付物**，必须进，大文件走 Git LFS。

一个坑记在这里：**`.gitignore` 不会按体积自动过滤**，新增的大文件得手动点名。
