## 未采用原因：局部侧颈转向集中

关键灰模中45°暗楔下端略短、90°嘴下上段更宽缓，正面集中暗区仍在。双方向掠射没有显示明显新增窄脊、横台或后肩折角，但45°反射中既有细长回转变短、变得更闭合。

已在原始900×1000图的固定矩形X360–425/Y535–640做一次同态Idle1真实三角网格补充诊断，共35条纵向、横向和对角截线。参数固定：0.0005world弧长步长、三次拟合、0.009world半窗与32px边距；没有更改原全局测量协议或为候选重新选窗口。

B最强局部峰约在world(0.12639,−0.31791,2.28961)，与反射回转区域吻合。横线弧宽缩短约26.70%，对角线约25.65%，峰形也收窄。结合实际反射变化，不能确认要求的整体不退化，故B不采用。

这是局部拟合诊断，源/候选同屏幕线命中的曲面位置有移动，拟合也会平滑三角网格细节；不据此宣称全身产生锐利折脊。完整参数、数据及九项来源哈希在[局部诊断](selected_patch_diagnostic.json)。

可能原因是当前曲率约束主要覆盖纵向嘴下Z2.31–2.40044，局部峰约Z2.28961及横向/对角方向没有被同一目标充分协调。这属于诊断推断。今后的方案修订应先解决这些方向和作用域之间的协调，不能仅增加相同场的幅度。
