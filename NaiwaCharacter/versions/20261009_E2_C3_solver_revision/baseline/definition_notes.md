# 固定 E2 基线说明

本基线仅打开一次指定 E2 工程。后续定义审计、剖面重测和眼接触边界均读取缓存数组，没有再次打开源工程。源 SHA256 保持 `317f62278d63217636bf393f831e2fb41ce21acfefbe21beed6ad6d4dc75f322`。

实际解剖方向为世界 `+Z` 向上、`−Y` 向前，左右沿 X。主体、眼球和嘴缝的世界矩阵均为单位矩阵；高光保留实际非单位矩阵。只有 `Naiwa unified golden body` 纳入 C3，隐藏代理 `Head and torso silhouette only` 及其余网格全部冻结。

协议的数值字段和对应数组是最终执行依据。首次诊断的肩释放下界 Z1.735 会触及腹部色块上缘，因此在生成任何候选前修正为 Z1.84，至 Z1.93 完全释放；原腹部色块上缘约 Z1.813 始终在最终域外。最终允许 58,433 个主体顶点参与，冻结 313,233 个顶点。

嘴部保护来自真实嘴缝与主体三角形交线，共 657 段。真实接触面原顶点独立冻结。初始距离定义在实际接触面顶点最远距 0.005171620364 上额外增加一条中位网格边长，过度冻结中央转角；在任何候选生成前改为该距离加 `1e−6` 数值余量，最终冻结距离 **0.005172620364**。释放终点 **0.044604122206** 保持，最终释放宽 **0.039431501842**。`measurement_protocol.json.protection_conflicts.notes` 中“固定 0.035 释放”是初始审计遗留描述；其后的明确修订记录、`scope` 数值与原顶点权重数组表示上述最终定义。没有缩短释放带。

中央曲率峰附近原顶点 293458 的权重仅 `5.0754e−8`，X≈0.08 附近代表顶点的权重约 0.0030099；真实口接触邻域仍严格限制削峰。目标通过下方释放域和侧颊传播转向，不能假定集中峰能够自由移动。

新的嘴下解剖测量域为 Z2.31 至真实中央口接触曲线中位 Z2.400440750287；前颈凹弧另测 Z2.05–2.31。固定弧长重采样步长 0.0005，三次局部拟合半窗 0.009。80%指标累计绝对展开切向角，检查连续区间两端所有断点及分数端点，以求最短弧宽。中央 E2 基线弧宽为 0.060507468422、曲率峰为 31.514462786；这些新口径不与历史 0.091/29.30 数字直接比较。

正面真实可见眼孔采用固定 world-zero 采样格、步长 0.0003。左/右等面积直径为 0.117094445729 / 0.117102274468，均值 D=0.117098360098，相对文档约 0.117114 差 −0.0134%。A/B 总位移上限由实测 D 计算为 0.004683934404 / 0.009367868808；眼窝局部上限 0.002927459002 包含于整体预算。

独立 `eye_contact_boundaries.npz/json` 保存真实眼球—皮肤交线及原始接触面顶点清单。左/右交线各 434/425 段；对应 233/225 个主体接触面顶点全部冻结。该补充文件没有改变既定数组、掩码或协议哈希。

`snapshot.json` 的 `array_prefix` 将对象名映射到 `baseline_arrays.npz` 中原始顶点顺序。Raw local 使用原始 float32，world 使用同一 float64 矩阵乘法；Idle1/Walk9/Laugh7/Jump6 各状态缓存独立实际求值数组和三角形。`body_scope_release_frozen.csv` 保存逐原始顶点作用域、释放、冻结、眼部标记及真实口接触曲线距离。
