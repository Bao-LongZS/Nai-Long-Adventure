## 本轮要解决的构造问题

当前 `eye_muzzle_sculpt.py::volume_eye` 使用：

```python
verts.append((x, skin(body, x, z) - cap + buried, z))
```

这把基础脸面的坡度逐点叠加到了眼体，实际眼体剖面呈倾斜的叶片。`0.20D` 是整只眼冠中央的最大 F 向凸出，绿区最大局部凸出约 `0.15D`；约 `0.75D` 的法向厚度包含埋入主体的封背，不能当作可见球体的厚度。

## 1. 固定工程与修改范围

从上述固定最新版建立新版本。保持黄色主体、嘴、骨架、姿态和头部截面不变，仅重建左右眼体，并重新贴合高光。

保留现有对象名、材质关联、父子关系与有效骨骼权重。修改生成入口及相关函数，使新版本可以重复生成；不要调用历史 `--from-primitives` 分支替代当前模型。该分支未包含最新的头部变形。

所有数值基于本文件的固定基线，不在每次运行时累乘。

## 2. 使用独立球面构造

删除可见眼体逐顶点跟随 `skin(x,z)` 的做法。黄色主体只用于求安装点 P、外向安装法线 n 及遮挡关系。

建立每眼局部正交基 `(u,v,n)`，使用单一球心 C 和半径 R：

```text
C = P - (R-h) n
Q(phi,theta) = C + R [sin(phi)cos(theta)u + sin(phi)sin(theta)v + cos(phi)n]
```

生成完整闭合球面。后部通过球心位置自然埋入黄色主体，不再叠加绝对工程单位 `0.12` 的回背位移。球面顶点不应随黄色皮肤的逐点起伏变形。

## 3. 输出两个构造候选

`D0` 是当前正面可见外径，不是新球体的完整直径。先以局部安装平面内的孔径半径 `a = 0.5D0` 定义两个初始方案：

| 方案 | 初始露出高度 h | 球半径 R=(a²+h²)/(2h) |
| --- | --- | --- |
| A | `0.30D0` | `0.5666667D0` |
| B | `0.40D0` | `0.5125D0` |

这些是构造对照值，不能声称为参考图反推的真实尺寸。这里 h 沿局部安装法线量取，不能与旧报告的全局 F 向凸出量混用。

每个方案按上述等面积定义重测实际正面可见外径与可见外缘中心。仅通过眼体自身半径和安装位置微调，使：

- 左右可见外径分别接近 `D0`，误差不超过 3%；
- 水平中心距接近 `S0`，误差不超过 2%；
- 每眼可见外缘中心的高度相对基线偏移不超过 `0.02D0`。

头部主体不能为满足眼睛测量而变形。校准后记录实际 R、h、球心和安装法线；不要只报告初始值。

## 4. 黑瞳与高光

黑瞳保持同一球面的材质分区，按新的球面纬线重新映射边界。正面可见黑瞳直径与眼外径之比保持约 `0.53`，不增加独立瞳孔凸块或厚壳。

安装法线与瞳孔视轴分别控制。基础候选先保留当前正面注视状态，不因诊断图使用 80°相机就把眼睛转向该方向。若球体修正后仍需测试瞳孔朝向，再另做左右镜像外展 20°、35°的对照；绿球几何和头部主体保持相同。

保留独立高光时，将它重新贴合球面，并从球体拟合和眼径测量中排除。

## 5. 几何验收

对未变形眼体网格做实际球面检查：

- 顶点到球心的距离应一致；最大相对半径残差不超过 `1e-4`。
- 经过球心的三个相互正交剖面应为圆。
- 网格闭合、法线向外，没有重复面或明显自交。
- 黑绿交界没有独立几何台阶。
- 安装处没有悬浮缝隙，前部露出连续，后部正常被主体遮挡。

再检查 Idle 第1帧的实际评估结果，确认骨骼或修改器没有把眼体重新拉成叶片。若变形来自权重或修改器，修正眼体对应设置并记录原因。

不能以手动设置 `complete_spherical_eye=True` 代替几何验收，也不能要求被脸部遮挡后的绿色投影在所有角度都为圆。
