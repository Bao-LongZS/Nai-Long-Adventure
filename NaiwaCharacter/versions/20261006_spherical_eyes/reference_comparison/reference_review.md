# 图1.3参考视角复核与 A/B 造型判断

**综合建议继续以 A 作为下一轮主候选，同时保留 B。** B 的正面黑瞳更居中，斜侧近眼外缘更接近圆；A 的眼球露出较低，参考视角的远眼暴露较少，更接近图1.3的遮挡关系。两者都改善了原眼体的斜长轮廓，但基础注视与远眼遮挡仍未同时吻合参考。本轮没有修改黄色头部、后脑、冠顶或颈前。

## 相机搜索与统一注册

相机搜索包含 A、B 各15组正交图：偏航40°、50°、60°、70°、80°，每个偏航都测试仰角−5°、0°、5°；随后在50°附近测试45°、55°及±2.5°仰角细调，并增加90mm、135mm长焦透视。原始相机与像素测量保存在 `../reference_search/camera_search.json`，完整15方向拼图分别为 [A](reference_camera_grid_A.png) 与 [B](reference_camera_grid_B.png)。

本报告共用的观察方向为：**偏航50°、仰角−2.5°、滚转0°；正交尺度0.86；目标(0,−0.12,2.425)，距离7；900×900输出；Standard、曝光−0.4。** 偏航从正前方F=−Y开始，正角度移向+X。原模型、A、B保持同一相机、灯光、曝光。长焦透视另保留在原始搜索中；B的个别评分最好值为135mm、50°/0°，但它没有提供足以代替共同正交相机的联合匹配。

原模型、A、B的主体和嘴相同，所以只从未改黄色冠顶和嘴求**一次**整体等比缩放与平移。900px模型原渲染到900×1130参考坐标的注册为：

```text
reference_x = 0.411755262024 × model_x + 245.388131365092
reference_y = 0.411755262024 × model_y − 17.159665982102
```

三个模型使用完全相同的系数，没有按每个候选的近眼直径重新放大。显示拼版再将参考坐标等比放大1.5倍，裁剪原点(270,40)，每栏620×470px；没有拉伸或镜像。原始渲染像素、注册系数、来源工程SHA256和参考原像素都保存在 [reference_review.json](reference_review.json)。工程SHA核对为 A `f251f5a0fc00fedf1df76fcc6286bc40e102406a536cb6c676a93e176cb71ca0`，B `d381f9ce3d505372467814d2dcb56e97e70b54864396a19453e60b93be8824fb`，对照渲染晚于两工程的保存时间。

## 正面、45°、90°及参考视角的判断

- **正面**：两者保持规定的可见等面积直径、中心距和高度，未再次放大整只眼。B的可见绿区与黑瞳关系更均衡；A下内侧被皮肤遮挡较多，黑瞳更靠该边。可见外缘都受皮肤遮挡，不能要求投影一定是完整圆，也不能将遮挡边的斜线认作眼网格已拉成叶片。
- **45°**：两种独立球体均较原模型厚实且近眼轮廓更圆。B近眼更圆、球冠更明显；A露出较克制。正面注视F=−Y会令近侧瞳孔在斜视图中靠向画面左侧，这属于视轴与安装法线分离后的投影效果。
- **90°**：两者的主体、嘴和头颈轮廓相同，差别来自眼球露出。A较低露出避免过强的凸球感，B更明显地突出于脸面；基础正面注视使黑瞳在侧面只剩靠前的一部分。A作为较保守的继续打磨基准更合适；B有助于保留更厚露出的构造对照。
- **共同参考视角50°/−2.5°**：B近眼圆度更接近参考，A远眼暴露较少。A的诊断评分为0.860，B在同角度约0.970；结合视觉判断和远眼遮挡，综合建议 A，但两者远眼仍明显大于参考。

评分把冠顶/嘴拟合残差、近眼位置、远眼位置、远/近可见外径比及近眼主轴比合在一起；远眼比差权重1.5，主轴比对数差权重0.5。它是人工权重的诊断排序，**不是参考真实相机的恢复**。仅偏向远眼遮挡可以选择更大的偏航，却会牺牲近眼圆度和嘴/眼/冠顶位置；例如80°/−5°的 A 远/近比降至约0.423，但近眼主轴比约1.510，位置残差也增大。旧80°/−5°不能沿用为已知参考相机。

## 注视对照

基础 A/B 工程保留正面注视F=−Y。另做镜像外展20°、35°，只改变同一球面的黑瞳材质分区与高光球面接触点，并分别输出共同参考相机和正面。渲染器核对眼球坐标哈希不变；测试没有保存进工程。

![基础、20度、35度临时注视对照](reference_gaze_comparison.png)

原图暗色内部中心相对近眼外缘中心约(−5.56,+2.64)px；基础 A、B 在共同注册下分别约(−18.46,+5.64)、(−17.44,+2.68)px。35°测试使近侧黑瞳更居中，更接近这张原图的注视观感，但远侧黑瞳变窄，而且无法修正远眼绿区遮挡。参考三维瞳孔视轴未知，所以这些测试仅说明后续可以独立调整注视；没有据此改变本轮基础候选。
