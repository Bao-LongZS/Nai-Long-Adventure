## 更新后的生成脚本

项目根目录 `NaiwaCharacter` 中：默认 `build_naiwa.py` 调用 `revise_head_reshape.py`；局部形体在 `head_reshape_sculpt.py`。每次都打开固定上一轮交付，复用与原工程 SHA256 匹配的 D0/W0 记录，不对本轮输出累乘。`eye_muzzle_sculpt.py` 的眼缘参数新增可选项，旧版本默认行为保留。

默认验收入口 `validate_head_revision.py` 调用 `validate_head_reshape.py`。比较渲染使用 `render_head_reshape_comparison.py`，拼图使用 `make_head_reshape_comparisons.py`。本目录的 `generation_scripts.zip` 保存本轮脚本及本地依赖快照；如需恢复，解压到保留上述固定基准的项目副本中。`generation_source_manifest.json` 记录源脚本 SHA256。

建议通过项目中的 `run_blender_stage.ps1` 分阶段运行，或给 Blender 加 `--python-exit-code 1`，避免 Python 异常被正常进程退出掩盖。原始模型和生成基准没有重复复制进本目录，也未生成额外草稿、自动备份或完整重复 ZIP。
