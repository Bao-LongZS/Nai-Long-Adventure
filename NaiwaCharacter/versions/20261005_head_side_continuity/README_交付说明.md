## 修整方式与保持项

重新拟合眼下至上颊的连续横截面，用五次曲线连接两端的截面宽度、切线和曲率，并用五次平滑权重衰减到周围原曲面。相同截面调整连续延伸到侧壁，没有另加独立鼓包。眼球连接周围设置零位移保护区，后侧权重平滑减弱。

仅调整主体 X 坐标，全部 Y、Z 坐标精确保持。眼线头宽、眼径、眼距、眼心高度、头顶和肩部保持；双眼、黑瞳、小高光和嘴缝的全部网格坐标、颜色及对象矩阵精确保持。前脸及喉部中央条带、范围外主体、身体、骨骼和权重保持。

正面眼下短竖段到上颊的转折有所柔化；45°远侧眼下的过渡稍顺。调整幅度细微，眼球下缘的自然转折仍可见。侧面脸、嘴及喉部的原轮廓保留，未发现新增凹槽、孤立鼓包或明显悬浮接缝。

## 更新后的脚本

项目 `NaiwaCharacter` 目录中的默认 `build_naiwa.py` 调用 `revise_head_side_continuity.py`，截面与权重修正在 `head_side_continuity_sculpt.py`。默认 `validate_head_revision.py` 调用 `validate_head_side_continuity.py`。每次生成重新打开固定上一轮工程，先核对原工程 SHA256，再使用记录的 D 和范围，避免反复运行累加位移。

`generation_scripts.zip` 保存本轮脚本及本地依赖快照、固定尺寸记录；解压到保留上一轮工程的项目副本后可复现。`generation_source_manifest.json` 记录各源文件 SHA256；`SHA256SUMS.json` 校验本目录交付文件。原生工程基准未重复打包。

生成：通过 `run_blender_stage.ps1` 运行 `build_naiwa.py`，完成标记为 `NAIWA_BUILD_OK`；可用 `--output` 指定另一个输出目录。只读验收完成标记为 `HEAD_SIDE_CONTINUITY_VALIDATION_OK`。对比渲染由 `render_head_reshape_comparison.py` 使用 `--before`、`--after`、`--output` 和 `--head-only` 完成，拼图由 `make_head_reshape_comparisons.py --head-only` 完成。
