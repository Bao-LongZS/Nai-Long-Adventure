## 停止原因

目标曲线以源曲面平顺为主，没有足够约束参考所需的前颈内收方向。例如中央前颈 Z≈2.156 的实际顶点 Y 变化约 `-0.001171`，在本工程 `-Y` 为前的坐标架中属于向前补形；它与该处参考轮廓所需方向冲突。仅提高同一场的幅度不能解决这个方向问题。

中央近嘴转角还受到真实接触面约束。基线诊断在生成 A 前将冻结范围确定为覆盖真实接触面顶点的最小距离加数值余量，未用未经实测的0.05D/0.20D。冻结距离 `0.005172620364`、完整释放终点 `0.044604122206`；仍保留不可自由移动的近口曲率峰。该拟合没有协调好这些硬接触与邻近释放段的最终曲率，实际出现中央及近侧局部峰增加。实际接触交线、原顶点清单及权重均在 `baseline/`。

本场的 A/B 幅度都被眼周局部预算限制在同一值 `1.917265207898`；B 会产生相同几何。结合 A 的关键检查无明确改善和参考误差变差，执行停止分支，不生成重复 B、不提高预算、不追加第三个候选。

只有通过关键图的选中候选才进入反射/掠射、动作、保存后完整验证与独立复建。本轮没有选中候选，因此未执行这些后续流程，也未导出新 FBX。A 保留为可审阅试验，不提升为正式版本。
